# Режим: применить готовое (кросс-тест)

Именно отсюда берутся отметки «кто опробовал» и замеры экономии.

1. Найди инструмент в `registry/tools/`. Возьми его из `main` или из ветки автора: `git checkout <ветка-автора> -- <путь>` в свою ветку. Ветку автора не меняй.
2. Прочитай README или контракт, объясни человеку, как запускать и на что смотреть.
3. Человек применяет на своём проекте (на копии). Помогай разбирать ошибки. Быстрые исправления — предложи в своей ветке и укажи в отчёте; большие доработки — предложить автору.
4. Заполни `templates/ntr/test-report.md` → `registry/tests/<дата>-<tool>-<user>.md`: проект, результат `ok` / `issues` / `fail`, затыки, время до/после (если удалось замерить).
5. Обнови статус в карточке: первый отчёт `ok` или `issues` от не-автора → `cross-tested`. `accepted` не ставь — это решение мейнтейнера.
6. Передай `ntr-retro`.
