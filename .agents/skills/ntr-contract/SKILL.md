# Разработка сценария

Цель — не решить задачу один раз, а получить **сценарий**, по которому коллега в чистом чате запустит агента и получит тот же результат. Один сценарий = один этап × один тип исходников × одна программа.

1. **Черновик до работы.** Создай `scenarios/<автор>_<тема>_<исходник>_<dcc>_v0.0.1.md` по шаблону `templates/ntr/scenario.md`. Чего не хватает для шаблона — выясни по `grill-me`: вопросы пакетом до 5, к каждому своя рекомендация. Обязательно:
   - что получить, с числами (лимит полигонов, размер атласа, тексель, платформа);
   - чего в результате быть не должно;
   - входы: какие файлы, в каком виде, что в них должно быть (слои DWG, листы PDF);
   - шаги по этапам пайплайна, у каждого проверка;
   - когда остановиться и спросить.
2. **Карточка сразу.** Создай `registry/tools/<id>.md` со `status: draft`, `line: contract`, ячейкой, этапом, `input`, `dcc`, `where` — на файл сценария. С этого момента этап на дашборде отмечен как «есть черновик сценария».
3. **Пилот** на маленьком куске (20–40 минут): один участок, один объект. Покажи человеку, поправь сценарий по результату.
4. **Прогон** по сценарию — шагами плана из файла сессии, с приёмкой каждого шага. Всё, что пришлось объяснять агенту сверх сценария, дописывай в сценарий: это и есть его содержание. Ошибки и тупики — в раздел «Не сработало».
5. **Проверка на чистоту.** Перечитай сценарий глазами коллеги: работает ли он без этой переписки, без локальных путей и названий проекта.
6. Передай `ntr-retro`: время, версия, выгрузка.
