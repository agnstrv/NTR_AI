# Режим: обсуждение

1. Уточни тему одним вопросом, если она расплывчата.
2. Обсуждай по существу: варианты, плюсы и минусы, своя рекомендация. Опирайся на репозиторий и `roadmap/`, а не на общие слова.
3. Если обсуждение превращается в задачу — скажи: «это уже `contract` / `tool`, переключиться?».
4. В конце (или по «сдаю») заполни `templates/ntr/discuss-note.md` → `notes/<дата>-<user>-<тема>.md`: решения, идеи для бэклога (с ячейкой/этапом), открытые вопросы, что предлагается сделать и кому.
5. Передай `ntr-retro`.
