## Как добавить ресурс

1. Найти реальный файл или получить его ссылку у контакта; проверить доступ.
2. Добавить ID, название, категорию, ссылку, происхождение/условия использования, форматы и версии, контакт и статус: заявлен / получен / проверен.
3. Для материала указать карты, разрешение и физический размер, если известен; для растения — название вида и факт замены аналогом. Не выдумывать неизвестные поля.
4. Сохранить небольшой эталон применения или превью. Другой художник должен найти и использовать ресурс без устного объяснения владельца.
