# Рома. НПМ ОКС

Персональные сценарии Ромы для обработки ОКС НПМ.

## Выбор сценария

На сообщение «Привет, работаю с ОКС НПМ» спросить: «Какой сценарий работы выбираем?»

Ответ «простой» запускает [НПМ. Легкая версия](<НПМ. Легкая версия/README.md>):

1. Очистка окон и подготовка маски стекла.
2. Копия меша, UV, запекание и карты, затем выдавливание основания на 2 метра вниз в рамках этого же этапа.

Если пользователь уже указал сценарий, не спрашивать повторно. Для другого сценария сначала установить подходящую инструкцию; не подменять его простым.

Основание: поручение Ромы от 12.10.2026. Параметры этого раздела относятся к персональному сценарию и не заменяют стандарты команды.
