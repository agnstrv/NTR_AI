# Рома. НПМ ОКС

Персональные сценарии Ромы для обработки ОКС НПМ.

## Выбор сценария

На сообщение «моделирую НПМ ОКС» (также «моделирую ОКС НПМ», «работаю с НПМ ОКС» или «работаю с ОКС НПМ») спросить: «Какая сложность у проекта — лёгкая или средняя?» Если сложность уже указана, повторно не спрашивать.

Ответ «лёгкая», «лёгкая геометрия» или «простой» выбирает папку `Рома. НПМ ОКС/НПМ. Легкая версия/`. Ответ «средняя», «средняя геометрия» или «средний» выбирает папку `Рома. НПМ ОКС/НПМ.Средняя версия/`. Перед работой прочитать README выбранной папки и выполнять её сценарии в установленном порядке. Если пользователь не знает сложность, помочь определить её по доступной архитектуре; не выбирать папку наугад.

Ответ «лёгкая» / «лёгкая геометрия» / «простой» запускает [НПМ. Легкая версия](<НПМ. Легкая версия/README.md>):

1. Очистка окон и подготовка маски стекла.
2. Копия меша, UV, запекание и карты, затем выдавливание основания на 2 метра вниз в рамках этого же этапа.

Если пользователь уже указал сценарий, не спрашивать повторно. Для другого сценария сначала установить подходящую инструкцию; не подменять его простым.

Основание: поручение Ромы от 12.10.2026. Параметры этого раздела относятся к персональному сценарию и не заменяют стандарты команды.

## Средний сценарий

Ответ «средний» или «средняя версия» открывает [НПМ.Средняя версия](<НПМ.Средняя версия/README.md>). При доступной архитектуре в Blender спросить «Приступаем?», получить проект и выбранный корпус, затем проанализировать его и рекомендовать лёгкую или сложную геометрию с объяснением. Уже полученное поручение начать и указанный корпус повторно не подтверждать. Для смешанного корпуса выделить участки разных подходов.

После моделирования и проверки геометрии средний сценарий продолжается [«Запеканием по средней проработке архитектуры»](<НПМ.Средняя версия/03-bake-and-maps.md>): совмещённые UV, карты, проверка артефактов и финальная выдача. Перед каждым новым мешем уточнить необходимость прозрачности и её исходный материал, если ответ ещё не получен.
