# НПМ. Легкая версия

Простой сценарий Ромы для ОКС НПМ. Редакция от 12.10.2026.

## Как запускается работа

1. Пользователь пишет: «Привет, работаю с ОКС НПМ» (или НПМ ОКС).
2. Ассистент спрашивает: «Какой сценарий работы выбираем?»
3. Пользователь отвечает: «Простой».
4. Ассистент читает оба документа ниже и начинает их последовательно. Выбор простого сценария разрешает весь цикл, включая выдавливание основания; повторное разрешение на переход между этапами не требуется.
5. Если проект или меш не указан, уточнить только недостающие данные. Не выбирать произвольный объект. Если сценарий уже назван в первом сообщении, повторно не спрашивать.

## Два этапа

1. [Очистка окон и подготовка маски стекла](01-window-cleanup.md).
2. [Копия меша, UV, запекание и карты — с выдавливанием основания](02-bake-and-maps.md).

Второй этап включает удаление закрывающих основание полигонов, выдавливание нижнего контура на 2 метра по мировой Z и дополнение UV/карт. Низ остаётся открытым. Существующие UV и используемые ими пиксели сохраняются.

## Что уточнить до обработки

- Название проекта и целевой меш, доступ к исходной сцене и изображениям, место сохранения.
- Неоднозначные участки: стекло, глухие панели, проходы, двери и ограждения. Не угадывать их назначение.
- Нужна ли карта прозрачности; если да — исходный материал с прозрачными участками. Стекло не становится прозрачным автоматически. Уже полученные ответы не переспрашивать.

Работать на независимой копии и сохранять согласованный резерв геометрии, UV и карт. Выполненные шаги не повторять автоматически при продолжении чата; сначала проверить актуальное состояние.

Это персональный рабочий сценарий Ромы, составленный по проверенным протоколам NPM-WINDOWS-001, а не изменение общего стандарта команды. Вариант «Запекание по средней проработке архитектуры» в этот простой сценарий не входит. Клиентские модели и текстуры остаются вне GitHub.
