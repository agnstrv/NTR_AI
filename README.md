# NTR — общая техническая база

Этот репозиторий хранит правила процесса, шаблоны и повторно используемые скрипты команды НПМ/ВПМ/ППТ/IFC. Клиентские альбомы, модели, DWG, текстуры и выдачи находятся на Google Drive NTR Architecture.

## Разделы

| Раздел | Назначение |
| --- | --- |
| `process/` | Получение данных, изменения, производство, проверки и выдача |
| `standards/` | Утверждённые технические требования по виду результата |
| `scripts/blender/`, `scripts/3dsmax/`, `scripts/checks/` | Код и инструкция к его запуску |
| `templates/` | Одинаковые карточки проекта, интервью и испытания автоматизации |
| `experiments/` | Результаты попыток, которые пока не стали общим инструментом |
| `interviews/` | Сводные выводы интервью без клиентских файлов |

Статус папок — каркас. Наличие раздела не означает, что требования в нём уже утверждены.

## Как добавить общее решение

1. Опишите повторяющуюся задачу и ограничения в задаче GitHub.
2. Укажите пример входа и ожидаемый результат, без публикации закрытых данных заказчика.
3. Разработайте скрипт или правило, проверьте на копии файла.
4. Запишите, в какой программе и версии оно проверено, как запускать и что человек должен проверить после запуска.
5. После проверки перенесите из `experiments/` в `scripts/` или `standards/` с записью об ответственном и принятии.

См. `AGENTS.md` для работы с Codex.
