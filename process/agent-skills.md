## Подключение
Codex поддерживает навыки в .agents/skills. Откройте проект в новой сессии и проверьте, что агент видит нужные навыки; дополнительно попросите назвать прочитанные инструкции. Не считайте установку подтверждённой только по наличию папки.
Для Claude Code добавлены проектные точки входа .claude/skills/<name>/SKILL.md: они читают единый исходник .agents/skills/<name>/SKILL.md и его материалы. Код навыков не дублируется. В новой сессии из корня репозитория проверьте обнаружение навыков. При совпадении названия со встроенным навыком проверяйте путь: нужен проектный навык Matt. В других средах используйте явное чтение исходного SKILL.md.
Если требуется native-установка в другой клиент, настройте её отдельно по документации конкретной версии; не устанавливайте вторую незакреплённую копию поверх общего набора.

## Применение в NTR
| Этап | Навык |
|---|---|
| Вопросы и согласование | grill-me → grilling |
| Архитектура | codebase-design |
| Термины и решения | domain-modeling |
| Тестируемое поведение | tdd |
| Проверка изменений | code-review |
| Инструкции для агентов | writing-for-agents |

Указание «Skill tool» означает загрузку названного навыка доступным средством либо чтение его SKILL.md. Поддержка субагентов и shell зависит от среды; при отсутствии — последовательный режим и явное ограничение.
Порядок NTR задан agent-harness.md: grill выполняется для неразрешённых вопросов на новой задаче; уже согласованное не спрашивать повторно.
Исходные навыки могут ссылаться на GLOSSARY.md, ADR или coding standards. Учитывайте существующие документы и сохраняйте результаты внутри относящегося инструмента/docs либо общего process при общекомандном решении. Отсутствие документа отмечайте; не выдумывайте правила.
Любое действие с main, Trello или внешними данными подчиняется AGENTS.md и team-workflow.md. AI-review не даёт права самостоятельной человеческой приёмки.

### Источник задачи для code-review
В NTR issue tracker — Trello; спецификация — предоставленный текст карточки и согласованное описание в jobs/<job-id>/task.md. Порядок проверки и приёмки задан в [team-workflow.md](team-workflow.md). Если connector недоступен, используйте переданный или экспортированный текст и явно укажите ограничение; если нет самой спецификации, запросите её. Команда /setup-matt-pocock-skills не входит в установленный набор и для этой настройки не требуется. Это адаптация NTR; закреплённые исходники Matt остаются без изменений.

## Команда проекта /push

Собственный навык NTR [push](../.agents/skills/push/SKILL.md) публикует наработки текущего чата по правилам команды; он не входит в закреплённые семь навыков Matt. Автор: nagornov-artem.

В Codex отправьте `/push` как сообщение агенту: корневой AGENTS.md направляет его в сценарий во всех подпапках. Нативный вызов навыка — `$push` или выбор из доступных skills; регистрация отдельного пункта `/push` в меню Codex этим изменением не обещается. В Claude Code добавлена проектная точка входа `.claude/skills/push/SKILL.md` для `/push`. Если клиент перехватывает неизвестную slash-команду, используйте `$push` в Codex либо явно попросите прочитать сценарий по пути.

Пример: `/push только общие выводы по UV`. Без уточнения агент учитывает весь относящийся к задаче комплект текущего чата. Клиентские модели и текстуры остаются внешними материалами; на GitHub попадают допустимые код, документация, отчёты и ссылки. Подробный процесс и границы полномочий заданы только в SKILL.md.

После получения изменения обновите рабочую ветку с сохранением локальной работы и проверьте из подпапки, что агент прочитал именно проектный сценарий. Наличие файлов не подтверждает обнаружение в клиенте. Нативные вызовы в Codex/Claude Code и на втором ПК пока не испытаны.

## Обновление
Версию меняем отдельным PR: сравнить upstream, проверить новые инструкции и зависимости, сохранить лицензию, обновить lock и проверить один сценарий. Автообновления с main внешнего репозитория не включены.
Этот набор в GitHub не исправляет неудавшуюся установку навыков в личном ChatGPT Work и не утверждает, что локальные клиенты команды уже настроены.

Источники: [Codex skills](https://learn.chatgpt.com/docs/build-skills), [upstream](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336).

Claude Code: [проектные навыки](https://code.claude.com/docs/en/skills). После merge PR — безопасно обновить локальную ветку; fetch сам рабочие файлы не обновляет. Если продолжаете старую ветку, сначала интегрируйте новые правила и навыки, сохранив текущую работу. Откройте новую сессию из корня репозитория и проверьте обнаружение grill-me и путь к исходнику. На ПК команды этот smoke-test ещё не выполнен.
