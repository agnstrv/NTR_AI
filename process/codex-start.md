# Как начать и продолжить задачу с Codex

1. Откройте [каталог](../resources/README.md) и [подходящий процесс](workflows.md).
2. Выберите одну задачу: структура / документация / эксперимент / работа по объекту. Для структуры не нужен полный комплект проекта; для эксперимента нужны только относящиеся к нему входы.
3. Передайте Codex текст задачи, README/AGENTS, выбранный процесс, ссылку на разрешённые входы, эталон, версии ПО и критерий результата. Если connector не открывает ссылку, приложите разрешённый файл в чат.
4. Работайте на копии. Сохраняйте результаты на Drive, код и протокол — в GitHub по согласованному процессу.
5. Заполните [эксперимент](../templates/automation-experiment.md) и [передачу](../templates/handoff.md). Незакрытая проверка явно остаётся незакрытой.

## Стартовый текст

> Задача: [одна конкретная операция]. Режим: [структура / документация / эксперимент / проект]. Прочитай README, AGENTS и [процесс]. Входы: [ссылки/файлы и версии]. Эталон: [ссылка]. Применимые требования: [источник, пункт, область; неизвестное отметить]. Среда: [редактор/версия/аддоны]. Ожидаемый результат: [файл и место]. Проверка: [критерии]. Работай на копии, не додумывай отсутствующие нормы. Сохрани параметры, время, проверки, исправления и следующий шаг так, чтобы другой коллега мог продолжить.

Для NAV-001 вместо моделей используются учебные метаданные; цель — две корректные карточки, заполненный протокол и передача коллеге. [Начать проверку навигации](navigation-pilot.md).
