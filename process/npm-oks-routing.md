# Сценарии Ромы: ОКС НПМ

Пути ниже указаны от корня репозитория. Существующие сценарии сохранены.


- На сообщение «моделирую НПМ ОКС» (также «моделирую ОКС НПМ», «работаю с НПМ ОКС» или «работаю с ОКС НПМ») спросить: «Какая сложность у проекта — лёгкая или средняя?» Если сложность уже указана, повторно не спрашивать.

- Ответ «лёгкая», «лёгкая геометрия» или «простой» выбирает папку `Рома. НПМ ОКС/НПМ. Легкая версия/`. Ответ «средняя», «средняя геометрия» или «средний» выбирает папку `Рома. НПМ ОКС/НПМ.Средняя версия/`. Перед работой прочитать README выбранной папки и выполнять её сценарии в установленном порядке. Если пользователь не знает сложность, помочь определить её по доступной архитектуре; не выбирать папку наугад. Выбор полного сценария разрешает его этапы; уточняй только недостающие входы и неоднозначные участки. В лёгкой версии выдавливание основания входит во второй этап.

- Ответ «средний» / «средняя версия» направляет в `Рома. НПМ ОКС/НПМ.Средняя версия/README.md`. При доступной архитектуре в Blender спроси «Приступаем?», получи проект и корпус, осмотри геометрию и объясни, какой подход подходит: лёгкая или сложная геометрия. Если начало и корпус уже заданы, не спрашивай повторно. Следуй выбранному протоколу; для сложного подхода покажи характерный участок до тиражирования. «Простой подход» в контексте моделирования средней версии не переключает на сценарий «НПМ. Легкая версия».

- В полном среднем сценарии после проверки моделирования выполняй `Рома. НПМ ОКС/НПМ.Средняя версия/03-bake-and-maps.md` — «Запекание по средней проработке архитектуры». Перед каждым новым мешем уточни необходимость карты прозрачности и исходный материал, если ещё неизвестны. Соблюдай совмещение UV по всем свойствам карт, чистые цвета, чёткость рам, разделение стекла и металла, финальные суффиксы карт. Ограничение пользователя только моделированием сохраняет приоритет.
