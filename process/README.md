# Процесс

1. Анастасия получает материалы и связывает письмо с папкой проекта.
2. Закреплённый моделлер анализирует достаточность исходных данных и сообщает о пробелах Анастасии.
3. Полученные файлы сохраняются без перезаписи. Частичное обновление связывается с листами и прежними версиями в паспорте.
4. Производство ведётся по нужному виду результата. Рабочие файлы могут оставаться локально; контрольные результаты размещаются на Drive.
5. Внутренняя и внешняя проверки фиксируются отдельно, затем оформляется финальная выдача.
