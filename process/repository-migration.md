## Проверки и ограничения

Проверяются относительные ссылки, синтаксис Python, JSON, хеши опубликованных VPM-скриптов, комплектность пакета и пути сборки. Результат технической проверки фиксируется в описании PR переноса. Запуск Blender и Synthes на этой миграции не заявляется: исполнителям нужно повторить профильный тест в своих версиях ПО. Навыки на ПК команды проверяются при первом запуске.

Существующие ветки интегрируйте с актуальным main до продолжения. Старые адреса на main больше не действуют; историческую версию можно открыть по commit. Не копируйте старые каталоги обратно.

Серверная защита main не включена доступным подключением. До настройки администратором участники соблюдают PR-процесс по AGENTS.md. Архивные слитые ветки могут оставаться в GitHub; для новой работы используйте main и новое имя work/<author>/<tool>/<job-id>.
