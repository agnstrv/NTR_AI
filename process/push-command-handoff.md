## Задача и критерии

Пользователь: «создадим команду /push, которая будет означать, что нужно текущие наработки чата выгрузить в репозиторий GitHub по правилам NTR_AI. Команда должна работать во всём проекте NTR_AI».

Критерии: корневой маршрут из любой подпапки; один источник сценария; сбор результатов текущего чата; сохранение чужих изменений; проверка всего публикуемого диапазона; исключение клиентских данных; commit/push своей ветки; честный результат при отсутствии доступа/идентичности; merge и accepted остаются по действующим правилам.

Архитектура: `.agents/skills/push/SKILL.md` — сценарий; AGENTS.md — маршрут; `.claude/skills/push/SKILL.md` — тонкая точка входа; YAML — отображение в Codex. Подключение и ограничения описаны в process/agent-skills.md, ссылки — в README и памятке. Отдельный инструмент в tools не создаётся: это общекомандная процедура. Существующих команд push в проекте при исследовании не найдено.

Фазы: исследование правил/документации → сценарий и точки входа → структурная проверка и независимый review → commit/push → передача. ## Область и ограничения

Проверки: git diff --check и штатный валидатор навыка пройдены; независимый AI-review и четыре логических сценария — [push-command-review.md](push-command-review.md), существенных замечаний нет. Проверены ссылки новых точек входа. GitHub-профиль публикации agnstrv, author-slug команды nagornov-artem; локальная Git identity для этого коммита задаётся только на время команды с подтверждённым noreply-адресом аккаунта, глобальные настройки не меняются.

Создание команды не запускает публикацию истории UV этого чата. Клиентские материалы и полный локальный контекст не включены. Нативная slash-команда меню Codex не регистрируется: `/push` — сообщение, распознаваемое корневой инструкцией; запасной вызов `$push`. Claude Code получает проектную skill-точку входа. Фактический клиентский smoke-test, второй ПК и человеческая приёмка пока не выполнены. Статус: prototype до проверки вызова в клиентах.
