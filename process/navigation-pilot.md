# NAV-001 Проверка навигации с исполнителями

Статус: материалы подготовлены; техническая проверка ассистентом и проверка людьми фиксируются отдельно. Проверка под аккаунтами участников ещё не проведена.

Это синтетические карточки без реальных карт/моделей и без клиентских исходников.

## Участник 1

Предлагаемый участник: Артём Нагорнов; участие ещё не подтверждено. Можно выбрать другого исполнителя.

- Открыть корневой README и найти каталог ресурсов, свой процесс и шаблон эксперимента.
- По каталогу найти NAV-001 и открыть inputs.json.
- В новом чате с Codex передать [стартовый контекст](codex-start.md) и задание: оформить две черновые карточки по JSON, отметить неизвестные поля.
- Сохранить result_<имя>_v01.md, протокол и handoff_<имя>_v01.md в папку NAV-001. Не заполнять неизвестное догадками.
- Записать недоступные ссылки, непонятные места и время.

## Участник 2

Предлагаемый участник: Вячеслав; участие ещё не подтверждено. Открывает только handoff первого участника, находит по нему входы/результат, сверяет карточки и сохраняет review_<имя>_v01.md с дальнейшим действием. Назначение участника не означает назначение разработчиком.

## Критерии завершения

- Оба человека подтвердили доступ к нужным ссылкам под своими аккаунтами.
- Первый нашёл входы, начал новый чат и сохранил действительный результат/протокол.
- Второй продолжил по записи передачи без устного объяснения.
- Есть ссылки на result, handoff и review, перечень неудобств и решение о правках.

До получения этих записей пункт «проверено с исполнителями» остаётся открытым. [Технический протокол](../experiments/NAV-001/README.md) не заменяет проверку людьми. Для настоящего моделирования позже добавляются отдельные реальные входы/эталоны и нормы.
