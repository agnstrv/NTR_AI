## Как обновлять

Текущая очередь и статусы ведутся в Trello. Issues и этот реестр сохраняют историю интервью; при уточнении данных сохраняйте источник. Отдельная Google-таблица пока не создана. Статус работы и применимость AI — разные поля. Ответственного назначать после подтверждения, критерии принятия — по актуальным требованиям и фактическому тесту. Новые разработки и протоколы — tools/ по правилам репозитория. Рабочие модели остаются в Drive.

До объединения с другими участниками сравнить входы, редактор, результат и критерии; похожие названия не делают запросы дублями. Связи между этими задачами описаны в отчёте. Полнота интервью участником не подтверждена; отчёт выдан по его просьбе.

Отчёт сохранён как снимок интервью: раздел «реально записано» описывает состояние **до интеграции**. По последующей команде Артёма отчёт загружен в Drive и добавлен сюда; 18 Issues созданы, назначение разработки не выполнено.
