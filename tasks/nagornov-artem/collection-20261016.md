Полный кейс не повторялся.

Ссылка между пакетами указывает в отдельную ветку; файлы пакетов не дублируются в ветке этой описи. Для code/tests и исторических материалов добавлены узкие исключения .gitattributes, чтобы Git сохранил проверенные байты CRLF/LF. Сверено содержимое staged blobs с manifest. Git-коммиты выполнены подключённой учётной записью agnstrv; автор разработки явно указан в README и slug веток.

- Compact Cut 1.0 менял кривизну длинными диагоналями; 1.1.0 сохранил исходные рёбра, 1.1.1 исправил загрузку старого backend. Это уже описано в canonical README и не копируется в новый инструмент.
- VPM: приоритет пользователя — совпадение разрезов. Сжатие на наклонных гранях и разные профили texel относятся к конкретным опытам. 600–1500 и 1000 px/m не объявляются общими нормами.
- Equalizer: не выполняет unwrap/pack; защищает Pin, не исправляет старые overlap, блокирует новые; единое введённое разрешение. Последний пользовательский кейс отменён из-за точности UV. Причина в конкретной грани не установлена; малые острова/большие координаты — гипотезы. В истории указаны пороги 0,001% плотности и 0,001° изменения углов при проверке сохранения формы; это параметры инструмента, не нормы команды.
- Окна: объединение импостов с допуском 0,05 м отвергнуто пользователем, изменения отменены. Наружные плейны и серединное заполнение — разные этапы; их нельзя объединять под видом одного проверенного алгоритма.
- НПМ: пользовательский ручной Low.blend выбран эталоном вместо Low_NPM_UV_v2.blend. Непрерывная UV-полоса нужна через угловые скругления для рисунка; изменение направления поверхности само по себе не требует шва. Мелкие острова на углах были отвергнуты. НПМ-черновик имел открытые стыки; численные результаты одного объекта не являются нормативами.
