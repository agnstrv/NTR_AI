Сейчас в работе

Незакрытые сессии из всех веток GitHub: задача открыта или передана в новый чат.

Кому напомнить

Факты из GitHub и реестра на момент сборки и одно предложение на человека. Точка — давность последней выгрузки: зелёная — меньше 7 дней, жёлтая — 7–13, красная — 14 и больше или выгрузок не было.

Активность команды (GitHub, живые данные)

Сессии

Одна строка — одна рабочая сессия с агентом: файл sessions/<дата>_<кто>_<тема>.md, который агент пишет в рабочей ветке. Собирается со всех веток GitHub. «Вручную → с ИИ» — минуты на ту же задачу; в счётчик замеров идут только строки с пометкой «замер».
