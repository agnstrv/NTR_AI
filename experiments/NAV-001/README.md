# NAV-001 Технический протокол

Цель: проверить связность документации, наличие входа на Drive и возможность сохранить передаваемый результат. Учебный inputs.json описывает две карточки, а не реальные производственные ассеты.

[Проверка с исполнителями](../../process/navigation-pilot.md). [Папка результата](https://drive.google.com/drive/folders/10WN8Yi-R4uiWiYtISf9pAYFlGXGFOH83). [Вход](https://drive.google.com/file/d/1bkW2SzxtNRAQ8MD-hH9Mfd3tT8lQLqzj/view?usp=drivesdk).

## Состояние

- Материалы подготовлены.
- Проверка ассистентом: ожидает проверки опубликованных ссылок и контрольного сохранения.
- Участник 1: ожидает участия.
- Участник 2: ожидает участия.
- Ни предметные модели, ни реальные библиотеки этим тестом не проверяются.

## Что сохранить

result_<имя>_v01.md — карточки и протокол; handoff_<имя>_v01.md — продолжение; review_<имя>_v01.md — проверка вторым участником. Отклонения и недоступные ссылки фиксируются явно.
