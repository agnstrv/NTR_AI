# Эксперименты

Здесь фиксируются попытки автоматизации до принятия в общую работу. Используйте `templates/automation-experiment.md`. Запись об успехе должна ссылаться на воспроизводимую проверку и человека, который принял результат.

Этот раздел сохраняет существующие адреса. Новые инструменты создаются по [правилам tools](../process/repository-structure.md) и остаются там при принятии. Перед работой проверьте [каталог](../tools/README.md); не создавайте повторную копию.


[VPM-GRID-001 — нарезка и UV/UDIM](VPM-GRID-001/README.md): прототип с опубликованными результатами; независимая проверка на проекте коллеги ещё требуется.
