Compact Circular Cut 1.1.1 — аддон для Blender 5.0+

Установка
1. В Preferences → Add-ons выберите Install from Disk и укажите
   compact_circular_cut_v1.1.1.zip. Распаковывать архив не нужно.
2. Включите Compact Circular Cut, если он не включился автоматически.
3. В 3D View нажмите N и откройте вкладку NPM.

Использование
1. В Object Mode создайте прямой замкнутый цилиндр минимум с 8 сторонами.
   Его размеры, поворот и число сторон определяют контур выреза.
2. Поставьте цилиндр так, чтобы он пересекал нужную поверхность.
3. Выделите цилиндр, затем с Shift выделите объект выреза последним:
   объект выреза должен быть активным.
4. Нажмите «Сделать вырез» во вкладке NPM.
   Команда также доступна через F3 → Compact Circular Cut и меню Object.

«Ширина перехода» задаётся относительно радиуса резака: 0.16 по умолчанию.
От каждой вершины контура идёт короткое ребро. Соседние рёбра сходятся
попарно к меньшему числу внешних вершин. Сам контур не упрощается.
Исходные рёбра и перегибы поверхности сохраняются в новой сетке.
На пересечениях исходных рёбер с контуром добавляются необходимые вершины:
они лежат на рёбрах профиля резака и не меняют его размер или форму.
Число вершин готового контура может поэтому превышать число сторон цилиндра.
Новые точки вычисляются по исходным граням в плоскости проекции выреза.
Цилиндр сохраняется и по умолчанию скрывается; действие отменяется Ctrl+Z.
Регистрация аддона не изменяет модель.

Для сквозного отверстия цилиндр пересекает обе стороны замкнутого меша.
Для глухого углубления один торец цилиндра должен находиться внутри меша.
На открытой тонкой поверхности получается открытый контур.

Ограничения
Это специализированное вычитание цилиндра. Резаки с фасками, конусностью,
изменением профиля, вырезы через внешний край и участки с уже существующими
отверстиями не поддерживаются. Не поддерживаются shape keys и вырезы через
более двух раздельных слоёв. Ошибка проверки не изменяет исходный меш.
Модификаторы целевого объекта остаются: вырез строится на базовой сетке.
UV поверхности интерполируются; UV новых внутренних стенок требуют
размещения в нужной области текстурного атласа. На произвольной кривизне
проверьте сглаживание после операции.

Если ранее запускали standalone-скрипт circular_cut_compact.py, перед
первым включением аддона перезапустите Blender, сохранив свою работу:
скрипт и аддон регистрируют одну и ту же команду.

Обновление с 1.0.0
Отключите аддон, установите ZIP 1.1.1 через Install from Disk и перезапустите
Blender, предварительно сохранив работу. Затем включите Compact Circular Cut.
Обновление не исправляет уже сделанный вырез автоматически: отмените старую
операцию или используйте исходный меш и повторите вырез новой версией.

В панели NPM должна отображаться строка «Версия 1.1.1 — сохранение исходных
рёбер». При обновлении теперь принудительно перезагружается и модуль геометрии:
Blender иногда перезагружает только интерфейс, оставляя старую логику выреза.
