# Стандартная плашка растения

[plant-card.json](plant-card.json) — сохранённая геометрия образца Ромы из первого опыта. Это общий примитив для сценария: 16 вершин, четыре пересекающиеся вертикальные плоскости через 45 градусов. Материалов, текстур, объектов проекта и его мировых координат здесь нет.

- Базовый габарит: 3 × 3 × 4 м; последнее число — высота.
- Origin: `(0, 0, 0)`, у основания растения, как у предоставленного образца. Незначительное исходное смещение геометрии в горизонтальной плоскости сохранено; нового центрирования не выполнялось.
- Вершины записаны относительно origin; Z направлена вверх. Исходный поворот образца уже учтён в вершинах.
- UV каждой из четырёх плоскостей сохранена и наложена на один прямоугольник. UV не меняется при выборе размеров вида.
- Конструкция одна для деревьев и кустарников; размеры видов агент уточняет по workflow.

## Восстановление в Blender

Для ручного добавления есть [plant-card.blend](plant-card.blend): `File → Append → plant-card.blend → Object → plant-card-template`. Библиотека содержит только один объект и его меш; сцен, материалов и изображений проекта в ней нет. Габариты рассчитаны на масштаб сцены `scale_length = 1` (одна единица Blender равна одному метру). Для другой системы единиц используй помощник ниже, который пересчитывает метры.

Переносимый источник геометрии — JSON; `.blend` является готовой библиотекой, полученной из него. При обновлении источника библиотеку нужно пересоздать и проверить совпадение origin, геометрии и UV.

Агент читает [create_plant_card.py](../src/create_plant_card.py) и вызывает функцию внутри Blender:

```python
import runpy

# tool_dir — абсолютный путь к tools/placement/album-plant-placement
helpers = runpy.run_path(str(tool_dir / "src" / "create_plant_card.py"))
obj = helpers["create_plant_card"](
    name="plant-card-template",
    size_m=(3.0, 3.0, 4.0),
    collection=target_collection,
)
```

`target_collection` — выбранная рабочая коллекция Blender. Без аргумента используется текущая коллекция. Чтение скрипта не создаёт объект; явный вызов функции создаёт новый объект в начале координат. Он не заменяет существующие объекты и не меняет выделение. Позицию и поворот при расстановке задаёт вызывающий код.

Размеры передаются в метрах; функция учитывает `scene.unit_settings.scale_length`. После восстановления агент проверяет реальные габариты, origin и UV в целевой сцене. Восстановление проверено в Blender 5.2.2 LTS; подробности — в [отчёте проверки](../docs/review.md). Другие версии требуют собственного повтора.

Используй этот образец по умолчанию. Просить человека создать его заново не нужно. Альтернативный образец сохраняй как отдельный согласованный вариант; стандартный JSON автоматически не перезаписывай.
