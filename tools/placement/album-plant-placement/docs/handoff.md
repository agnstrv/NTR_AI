## Что получить коллеге

Сначала сохранить свою локальную работу, получить ветку через fetch и открыть её в отдельном рабочем каталоге либо переключиться на неё безопасным способом. Существующие незакоммиченные изменения сохраняются. Прочитать [README](../README.md) и [workflow](../workflow.md), передать агенту стартовое сообщение из README.

Пакет включает инструкцию, разбор первого опыта, вопросы для обсуждения, AI-review, общий шаблон `assets/plant-card.json`, готовую библиотеку `assets/plant-card.blend` и помощник `src/create_plant_card.py`. Готовая библиотека предназначена для сцены с unit scale 1; помощник принимает размеры в метрах и учитывает масштаб сцены.

Клиентские PDF, рабочие `.blend`, скриншоты и таблицы координат первого опыта в Git не включены. Для повторения на другом проекте участник предоставляет свои разрешённые исходники. Для повторения именно первого опыта требуется отдельная выдача входов через хранилище проекта; она пока не подготовлена.

## Состояние и ограничения

Документация и восстановление плашки проверены отдельно. Параметры и границы проверок перечислены в [review.md](review.md). Восстановление тестировалось в Blender 5.2.2 LTS без изменения рабочей сцены. Другой ПК, другая версия Blender, текстуры растений и универсальный скрипт массовой расстановки не проверены и не поставляются.

Существующие изменения `tools/geometry/compact-circular-cut` относятся к другой работе и исключены из коммита. В этой задаче разрешён только обычный commit + push указанной ветки; main сохраняется.

Следующее действие коллеги: повторить чтение плана, точки и пробную расстановку по workflow на своём участке; сохранить среду, параметры, результат и ручную доводку. Решение о применимости и возможном слиянии принять по правилам NTR.
