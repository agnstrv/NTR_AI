# NAV-001 Проверка навигации

Статус: задание подготовлено, участие исполнителей ещё не подтверждено.

Откройте GitHub agnstrv/NTR_AI, найдите resources/README.md, process/codex-start.md и templates/automation-experiment.md. Затем найдите inputs.json в папке NAV-001 на Drive.

Конкретная задача для Codex: по синтетическому inputs.json оформить две черновые карточки ресурса. Сохранить категорию, набор карт и известные размеры; отсутствующие поля явно отметить. Не подбирать реальные текстуры и не объявлять карточки пригодными для производства. Заполнить протокол эксперимента, указав, что проверяется навигация, а не моделирование.

Сохраните результат как result_<имя>_v01.md в этой папке Drive. В конце запишите следующий шаг, ссылки на вход и результат, найденные препятствия, время и способ продолжения коллегой. Создайте запись handoff_<имя>_v01.md по приложенному шаблону.

Второй исполнитель открывает только передачу handoff и по её ссылкам находит входы, инструкцию и результат; сверяет две карточки с JSON, записывает недостающие поля и следующий шаг. Сохраняет review_<имя>_v01.md. Для продолжения работы не должно требоваться устное объяснение автора.

Результат считается подтверждённым людьми только после этих двух записей и указания, какие ссылки удалось открыть под аккаунтами исполнителей.
