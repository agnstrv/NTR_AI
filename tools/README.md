# Каталог разработок
Перед созданием инструмента найдите здесь существующий канонический путь. Направления и формат: [структура](../process/repository-structure.md).

| Направление | Разработка | Канонический источник | Готовность по доступным данным |
|---|---|---|---|
| geometry | COMPACT-CUT-001 | [эксперимент](../experiments/COMPACT-CUT-001/README.md) | Прототип; приёмка всей командой не установлена |
| uv | VPM-GRID-001 | [ветка и PR #27](https://github.com/agnstrv/NTR_AI/pull/27) | Незавершённое принятие, отсутствует в main |
| textures / geometry | NPM OKS — сценарии Ромы | [выбор сценария](<../Рома. НПМ ОКС/README.md>) | Инструкции опубликованы; статусы отдельных операций в Trello требуют сверки |
| textures | NPM-WINDOWS-001 — прежние протоколы | [очистка окон](../experiments/NPM-WINDOWS-001/01-window-cleanup.md) | Исторические материалы; перед правкой сверить со сценариями Ромы |
| infrastructure | NAV-001 | [навигационный пилот](../experiments/NAV-001/README.md) | Отдельный опыт передачи |
| infrastructure | team-workflow | [правила команды](../process/team-workflow.md) | Документы; пилот на двух ПК не проведён |

Это исходный каталог, не подтверждение полной инвентаризации локальных ПК. Другие инструменты добавляются по результатам первичного сбора.
Новые папки создавайте по фактической работе; пустые заготовки направлений не нужны.
