# Каталог разработок

Один инструмент — один постоянный путь. Статус относится к указанным проверкам; присутствие в main само по себе не означает производственную готовность.

| Направление | Инструмент | Статус и следующий шаг |
|---|---|---|
| geometry | [compact-circular-cut](geometry/compact-circular-cut/README.md) | prototype; независимый повтор после успешного пользовательского примера |
| uv | [vpm-grid](uv/vpm-grid/README.md) | prototype; опубликованы испытания Blender 5.0, нужна проверка коллегой |
| textures / geometry | [npm-oks — сценарии Ромы](textures/npm-oks/README.md) | prototype; тип — workflow. Выбор лёгкой/средней версии, независимая приёмка не установлена |
| textures | [npm-window-bake](textures/npm-window-bake/README.md) | исторические протоколы; канонический рабочий сценарий — npm-oks |
| collisions | [building-ucx](collisions/building-ucx/README.md) | prototype; кейс Ostrov, оценка пользователя около 60%, требуется ручная доводка и независимая проверка |
| infrastructure | [navigation-pilot](infrastructure/navigation-pilot/README.md) | research; учебная проверка передачи |

[Правила структуры](../process/repository-structure.md) · [Начать работу](../docs/start-here.md)

Авторство и исходные ID сохранены в документах инструментов. Набор не включает наработки, которые ещё остались только на ПК участников. Для их сбора используйте [промпт №1](../prompts/01-collect-local-work.md).
