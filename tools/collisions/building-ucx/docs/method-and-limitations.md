# Методы и ограничения

Первая попытка дала 123569 частей и была отвергнута. Причины: разбиение мелкой
воксельной оболочки, ориентация по мировым осям вместо направления архитектуры,
отсутствие раннего бюджета, попытка точно воспроизвести детали. Проверка расстояния
до поверхности также ошибочно отбрасывала допустимые внутренние объёмы здания.

Повторная попытка использовала контуры, крупные призмы, объединение общих контуров
по высоте, отдельные плиты навесов и тонкие барьеры. Промежуточное тело из 597 частей
пользователь оценил как значительно лучше. Это подтверждение направления, не приёмка.

## Что выделено в код

- `contours.convex_parts`: constrained Delaunay с последующим слиянием смежных
  треугольников в выпуклые контуры. Результат зависит от первоначального разбиения;
  это эвристика, не минимальное число объёмов. Не все части будут четырёхугольными.
- `contours.prism`: закрытые призмы по выпуклому контуру.
- `geometry`: double-precision ConvexHull вместо плоскости по первой почти
  вырожденной тройке. Замыкание результата после разрезов; ориентированные треугольники.
- `split_with_gap`: две закрытые части относительно одной общей плоскости.

## Что остаётся экспериментальным

Двойная точность улучшила промежуточные массивы, но не решила все проблемы экспорта.
У сохранённой модели проверки разошлись: общий ATRIUM checker пропустил все части,
строгая проверка граней — лишь часть. Нельзя считать широкий допуск checker доказательством.

Численные пороги, округление и отбрасывание малых объёмов могут терять геометрию.
Остаток, не выдержавший inset, не обязательно микроскопический. В эксперименте удалённые
остатки проверяли отдельно по плотной сетке точек; это не доказывает допуск всего здания.
`rebuild` заполняет вогнутости, поэтому использовать его на исходном здании целиком нельзя.

При контурном укрупнении mitre-buffer может выходить за заданный радиус на углах;
для евклидова допуска нужен круглый buffer и контроль исходной формы. Вертикальная
ошибка, горизонтальная ошибка, упрощение и раздвижка частей расходуют общий допуск.
Один контроль только XY недостаточен. Для вогнутой n-gon грани среднее вершин
может лежать снаружи: контрольные точки брать после корректной триангуляции.

Промежуточные объёмы нельзя объединять в один объект ради счётчика, если внутри
остаются раздельные или вогнутые оболочки. Ориентация кубов и повторное объединение
соседних объёмов полезнее такого обхода лимита.
