# Передача коллегам

Начните с README инструмента и docs/case-rules.md. Рабочая ветка:
`work/nagornov-artem/building-ucx/draft-artem-009-ostrov`.
Публикуется прототип, а не готовый производственный генератор.

Следующий технический шаг: устранить расхождение проверки граней после экспорта
в Blender на малом воспроизводимом синтетическом примере; затем проверить перенос
на реальном объекте коллеги. Далее — общая сборка с фасадными поясами в лимите,
пересечения, фактические зазоры и двусторонний допуск. Только после этого возможна
новая производственная выдача. Текущий CLI обрабатывает подготовленный 2D-контур.

Для повторения исходного кейса запросите модель у владельца карточки; клиентского
бинарника и сеток в этой ветке нет. Независимая человеческая приёмка обязательна
для `accepted`; AI-review проверяет только текущую публикацию.

Trello при упаковке не изменялся. Текст для обновления карточки после публикации:
«Опубликованы геометрическое ядро building-ucx, согласованные правила кейса и отчёт
ограничений. Статус prototype. Ветка work/nagornov-artem/building-ucx/draft-artem-009-ostrov.
Код проходит указанные в review синтетические проверки; полного генератора и
человеческой приёмки нет. Следующий шаг — проверка экспорта на малом примере и
повтор на проекте коллеги. Клиентская модель в GitHub не загружалась».
