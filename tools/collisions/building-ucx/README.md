# Building UCX — геометрическое ядро и правила моделирования

**Статус: prototype. Не готовый автоматический генератор коллизии здания.**
Автор опыта: пользователь чата «Коллизия ОКС» и Codex; историческая карточка заведена от Артёма Сафро. Автор кода и упаковки: Codex.
Ветка продолжения сохраняет исторический идентификатор автора `nagornov-artem`.
Публикация: 28.10.2026. Человеческая приёмка и проверка на проекте коллеги не выполнены.

Задача: [DRAFT-artem-009](https://github.com/agnstrv/NTR_AI/issues/9),
[карточка Trello](https://trello.com/c/CB5LIDqR).
Содержимое карточки при упаковке не перечитывалось; спецификация взята из согласованного диалога.

Пакет содержит выделенные из производственного эксперимента операции: выпуклую
оболочку в двойной точности, разность выпуклых тел, закрытый разрез с зазором,
разбиение плоского контура с отверстиями на выпуклые призмы.
Есть запускаемый CLI для **уже подготовленного контура**. Извлечение контура из
произвольного `.blend`, распознавание окон и ограждений, общая сборка, проверка
допуска и экспорт UCX в Blender сюда не включены: прежние скрипты зависели от
конкретных индексов и координат клиентской модели и содержали нерешённые ошибки.

## Запуск

Нужен отдельный Python 3.11+ с NumPy, SciPy и Shapely. Не копируйте бинарные
библиотеки другого Python в встроенный Python Blender.
Из папки этого инструмента:

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install .
.venv/Scripts/python -m unittest discover -s tests -v
.venv/Scripts/python -m building_ucx examples/footprint.json candidates.json --max-parts 999
```

`examples/footprint.json` — синтетический контур, не данные клиента.
Выход создаётся только по новому пути; существующий файл не перезаписывается.
Число 999 в примере относится к описанному кейсу; на новом объекте задайте
согласованный бюджет. CLI не применяет зазоры и не подтверждает отклонение от
исходной модели — эти флаги явно записаны в выходном JSON.
Отверстия контура сохраняются после округления к сетке 1 мм; элементы меньше
этой сетки могут исчезнуть. Сетка округления и малые пороги
площади унаследованы от эксперимента; тонкие элементы нужно проверять отдельно.

Геометрические функции находятся в `src/building_ucx/geometry.py`.
Вход: `{'vertices': Nx3, 'faces': [[индексы], ...]}` в единой системе координат,
в метрах. `rebuild` строит оболочку точек и **заполняет вогнутости**; это не
валидатор произвольной сетки. Boolean-функции принимают только уже выпуклые тела.
`subtract` возвращает `(parts, discarded_volume)`; внутренний epsilon исторического
алгоритма также может отсечь очень малые пересечения. Проверяйте баланс объёма и
покрытие; отсутствие исключения не означает пригодность коллизии.
