## Память для продолжения

Сначала прочитать [кейс](cases/case-001-ostrov/case.md) и [handoff](jobs/draft-artem-009-ostrov/handoff.md). Не начинать заново с мелкого воксельного разбиения.
17.10.2026 пользователь оценил результат примерно на 60%: удовлетворительно, но требуется немало ручной доработки. Это успешная промежуточная основа для дальнейшей работы, без статуса accepted.

Краткий порядок: примеры пользователя → обводка основной оболочки по стенам и стеклу → замыкание → крупные ориентированные выпуклые объёмы → детали → стыки → проверка сохранённой копии → визуальная оценка человеком.
Числа 25 см, 2 мм и 999 относятся только к этому согласованному кейсу. Для другого проекта нужны его требования.
Клиентская геометрия и привязанные к ней скрипты/массивы остаются вне GitHub. Документация не заменяет исходные локальные материалы и не обеспечивает запуск одним действием.
