# Порядок применения на новом объекте

1. Согласовать бюджет частей, допуск, зазоры, обработку окон, ограждений и лестниц.
   Значения из кейса не переносить автоматически. Зафиксировать единицы и матрицы.
2. Скопировать сцену. Записать версию Blender и контрольные суммы исходных мешей.
   Для фонового запуска отключить autoexec; открытой сценой пользователя не управлять.
3. Вручную или отдельным проверенным инструментом выделить основной контур, высоты
   уступов, дворы, проезды и консоли. Стекло учитывать согласно заданию.
4. Проверить один характерный узел по виду сбоку и сверху. Оценить число частей на
   всё здание с резервом на навесы, перила и технические элементы.
5. Создавать крупные ориентированные объёмы. Сначала замкнуть основной контур,
   затем разрезать по вогнутым изгибам. Не следовать триангуляции исходного меша.
   Общий контур на нескольких этажах должен проходить через всю соответствующую высоту.
6. Добавить отдельные крупные элементы. Прямые ограждения и поручни объединять по
   секциям; лестницы — по маршам; ламели — по согласованным общим покрытиям.
7. Убирать перекрытия при заранее выбранном приоритете: целый скат и тонкий барьер
   не должны превращаться в десятки фрагментов от последующих разрезов корпуса.
   После Boolean перестроить выпуклую оболочку и повторить проверки.
8. Раздвигать контактные части относительно единой плоскости разреза. При зазоре
   2 мм каждая сторона отступает от этой плоскости на 1 мм. Не применять глобальный
   inset ко всем внешним граням: это меняет толщину ограждений.
9. Проверить количество, замкнутость, выпуклость, наружные нормали, объём,
   пересечения, фактические зазоры и сохранность проходов. Проверить отклонение
   в обе стороны; вершины и центры треугольников — только выборочная проверка.
10. Сохранить и повторно открыть `.blend`. Проверять именно сохранённую сетку,
    а не только промежуточные массивы. Несогласие проверок — нерешённое замечание.
    Передать файл с фактическим статусом и ограничениями для человеческой приёмки.

Этот порядок содержит ручные этапы. CLI данного пакета реализует только разбиение
подготовленного плоского контура, а низкоуровневые функции — отдельные операции
над выпуклыми телами. Автоматической команды выполнения всех десяти этапов нет.
