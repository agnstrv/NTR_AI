# UV Texel Equalizer 1.2.2 — инструкция

Аддон для Blender: приводит UV-острова одного меша к заданной плотности пикселей и отдельно проверяет зеркальность и направление UV. Автор разработки: Nagornov Artem (nagornov-artem). Пакет не требует установки ATRIUM AGR или дополнительных Python-библиотек.

**Новое в 1.2.2:** «Допуск плотности (доля)» по умолчанию **0.00002**, то есть **0,002%**. Это точность достижения текселя, а не сам тексель. Исходные плотности островов могут отличаться.

## 1. Установка

1. Сохраните `uv-texel-equalizer-v1-2-2.zip`. Для установки распаковывать ZIP не нужно.
2. В Blender откройте **Edit → Preferences → Add-ons**, меню в правом верхнем углу → **Install from Disk…**. Выберите ZIP и подтвердите установку.
3. Убедитесь, что **UV Texel Equalizer** включён. При обновлении установите новый ZIP поверх предыдущей версии и перезапустите Blender.
4. Откройте **UV Editor**, наведите курсор на его область, нажмите **N** и выберите вкладку **Texel**. Если вкладки нет, проверьте включение аддона и тип редактора.

Проверено в Blender **5.0.0**. В исходнике заявлены 4.3+/5.x; другие версии в этой поставке не испытывались. Сначала проверьте аддон на копии своего проекта. Инструкция по установке: https://docs.blender.org/manual/en/5.0/editors/preferences/addons.html

## 2. Перед запуском

- Выберите один объект типа Mesh с готовой UV-развёрткой. Обрабатывается **весь активный меш**, включая скрытые и невыделенные грани, а не только выделенные UV.
- Проверьте единицы и масштаб модели. Тексель измеряется в **пикселях на метр (px/m)**; учитываются Unit Scale сцены и масштаб объекта. Модификаторы при расчёте не вычисляются.
- Укажите реальную **ширину и высоту текстуры в пикселях**. Для текстуры 2048×2048 введите 2048 и 2048. Разрешение изображения и желаемый тексель — разные параметры.
- Поле «UV-слой» можно оставить пустым: будет использован активный UV-слой. Либо введите точное имя нужного слоя.

Для всех островов используется одно заданное разрешение текстуры. Различающиеся разрешения материалов и UDIM не определяются автоматически.

## 3. Приведение к заданному текселю

1. В «Привести к» выберите **«Заданному текселю»**.
2. Введите положительное значение **«Целевой тексель, px/m»** по требованиям своего проекта. Пример: 512 означает 512 пикселей на метр; это пример, а не обязательная норма. Ноль означает «цель не задана» и блокирует применение.
3. Оставьте **«Допуск плотности (доля)» = 0.00002**. После открытия старого `.blend` проверьте это поле: ранее сохранённое значение может остаться прежним. При необходимости введите `0.00002` вручную или сбросьте **только это поле** к значению по умолчанию.
4. Нажмите **«Проверить плотность и растяжения»**. Проверка не меняет координаты UV. При исходных искажениях используйте **«Выделить растянутые грани»** и проверьте развёртку.
5. Нажмите **«Выровнять тексель всех островов»**. После успешного выполнения проверьте результат на модели и свободное место на UV.

Например, острова с исходной плотностью 256 и 1024 px/m при цели 512 приводятся к 512 в пределах допуска. Каждый остров масштабируется целиком с одинаковым коэффициентом по U и V. Геометрия, материалы и координаты других UV-слоёв сохраняются. Расположение центра острова при масштабировании сохраняется, но острова могут вырасти, пересечься или выйти за 0–1. Автоматической упаковки, unwrap и перемещения островов для освобождения места нет.

Равномерный масштаб сохраняет форму в пределах численных проверок. Он **не исправляет уже существующие растяжения** внутри острова. Проверка исходных искажений, когда включена соответствующая опция, блокирует применение на таких островах.

## 4. Что означает допуск 0.00002

Сравнивается максимальная относительная ошибка плотности островов: `abs(полученная плотность / цель − 1)`. Значение **0.00002 = 0,002%**. Например, при цели 20 px/m допустимая разница — примерно 0,0004 px/m.

Blender хранит UV-координаты в float32, поэтому произвольный масштаб может немного округляться. Сообщение «Не достигнут допуск плотности: 1.11e-05» означает ошибку около 0,00111%; она сама по себе укладывается в новый допуск. Другие проверки всё равно могут остановить операцию.

Допуск также участвует в существующих внутренних проверках формы и ориентации. Для относительного изменения анизотропии используется `max(0.00001, 5 × допуск)`: при новом значении это 0.0001, или 0,01%. Фиксированный лимит изменения угловой ошибки 0,001° сохранён. Изменён только default общего параметра; алгоритм проверок не переписан.

## 5. Среднее вместо заданной цели

Выберите **«Среднему значению»**. Доступны среднее с сохранением суммарной площади UV, арифметическое по островам и среднее с весом по площади поверхности. В этом режиме цель вычисляется автоматически. Для выполнения конкретной нормы проекта используйте режим заданного текселя.

## 6. Проверка зеркальности и направления

Это отдельные кнопки в разделе **«Ориентация UV относительно модели»**:

1. Выберите ось «Верх модели» — обычно мировая Z. Для горизонтальных граней используется дополнительная ось — по умолчанию мировая Y.
2. Нажмите **«Проверить ориентацию островов»**.
3. Включите нужные опции исправления зеркальности и направления верха, затем нажмите **«Исправить зеркальность и верх UV»**.

Остров поворачивается/отражается целиком. При противоречивом направлении верха внутри острова или недостатке точности операция откажет. Проверьте такой остров вручную. Ориентация UV не исправляет геометрические нормали и не устанавливает заданную плотность вместо отдельного выравнивания.

## 7. Сообщения и действия

| Сообщение | Что проверить |
|---|---|
| Цель не задана | Введите положительный целевой тексель. |
| Исходные искажения | Выполните аудит, выделите растянутые грани, проверьте форму UV. Отключение строгой проверки не исправляет растяжения. |
| Не достигнут допуск плотности | Проверьте значение поля, особенно в старом `.blend`. При 0.00002 результат должен укладываться в 0,002%; больший отказ требует проверки точности координат. |
| Точности UV недостаточно для сохранения формы при масштабировании | Аддон выделит проблемные полигоны в Edit Mode. Причиной могут быть узкие сегменты внутри обычных островов, большие координаты или сильное уменьшение UV. |
| Масштабирование переместит закреплённый UV | Проверьте Pin. Снимайте закрепление, только если его разрешено менять по задаче. |
| Появится новое пересечение островов | Освободите место между островами самостоятельно; упаковка не выполняется. |
| Недостаточно точности для поворота | Проверьте указанный остров и его координаты; автоматическое выделение проблемных граней реализовано для отказа формы при масштабировании, не для всех ошибок ориентации. |

При отказе до записи координаты UV не меняются. При отказе формы во время масштабирования меняются **выделение и режим**: отмечаются все найденные проблемные полигоны и их UV, ранее скрытые проблемные грани показываются, прочее выделение снимается. Это диагностика, а не успешное выравнивание. Номера полигонов в сообщении начинаются с **1**.

## 8. Отчёт, отмена и передача коллеге

Отчёт находится внутри Blender: **Text Editor → список текстов → `Texel_Equalizer_Report.json`**. Там указаны цель, плотности, допуск, исходные искажения; при отказе формы — номера граней и метрики. `applied=true` означает выполненное UV-преобразование; `applied=false` — отсутствие применения. Диагностическое выделение может завершаться WARNING с `applied=false`.

Успешное изменение UV отменяется **Ctrl+Z**. Аддон не сохраняет `.blend` автоматически. После проверки результата сохраните проект самостоятельно.

Передайте коллеге **ZIP аддона и эту инструкцию**. Клиентские модели, текстуры и отчёты вашей сцены для установки не нужны. Передайте отдельно согласованные параметры: единицы модели, разрешение текстуры, целевой тексель и нужный UV-слой. После установки коллега должен проверить параметры в своём файле.

Происхождение: принципы проверки углов и зеркальности адаптированы из предоставленного ATRIUM AGR 2.0 (Timofei Zhilin); сам ATRIUM AGR в ZIP не входит. Собственная новая лицензия сторонним адаптациям не назначена; условия внешнего распространения требуют уточнения у правообладателя. Поставка подготовлена для передачи в рамках командной работы.
