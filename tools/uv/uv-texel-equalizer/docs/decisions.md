# Архитектура и решения

Первичный сбор 16.10.2026 сохраняет существующий однофайловый аддон 1.1.0; алгоритмы не переписываются. Активный mesh/UV + world transform + scene units + разрешение → snapshot и анализ островов/треугольников → предложение новых UV → проверки float32/формы/пересечений → атомарная запись или отказ. Плотность и ориентация — отдельные операции. Отчёт создаётся в Blender Text datablock `Texel_Equalizer_Report.json`.

Плотность: корень из pixel UV area / world area m²; default AREA_RMS. Масштаб каждого острова равномерный относительно bbox center. Ориентация: winding с учётом handedness, проекция world Z с fallback Y, отражение U и поворот в пиксельной метрике. Неоднозначные направления требуют ручного решения; перетриангуляция/новые швы не выполняются.

Strict-защиты исходного stretch и intra-island variation, pin, shared mesh data, UV overlap и float32 сохранены. Изменение допуска ради прохождения пользовательского precision-abort при упаковке не выполнялось: это могло бы изменить контракт. Откат — Ctrl+Z или возврат к копии сцены; исходники на диске не изменены. Объединение со скриптами окон не выполнено: связь карточки общая, интерфейсы и риски разные.
