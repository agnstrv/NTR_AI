# UV Texel Equalizer 1.2.2

Автор разработки и передающий участник: Nagornov Artem (`nagornov-artem`). Публикация установочного комплекта версии 1.2.2, без изменения байтов ZIP и инструкции. Независимая приёмка на проекте коллеги не подтверждена; accepted не присвоен.

[Скачать ZIP](dist/uv-texel-equalizer-v1-2-2.zip?raw=true) · [Инструкция](docs/guide-1-2-2.md)

Аддон приводит все UV-острова активного меша к заданному текселю и отдельно проверяет зеркальность и направление. Панель: UV Editor → N → Texel. Допуск плотности по умолчанию 0.00002 (0,002%). Не делает unwrap и упаковку. Подробные ограничения, диагностика и порядок применения включены в инструкцию и ZIP.

По передаче автора пройден 51 тест; в этой задаче Blender и эти тесты повторно не запускались. Инструкция указывает проверку в Blender 5.0.0. Сохраните копию модели до запуска.

Связь: DRAFT-artem-n-20261007-009, [Trello XRE5EEOB](https://trello.com/c/XRE5EEOB). Историческая версия 1.1.0 с исходниками и тестами находится в ветке `work/nagornov-artem/uv-texel-equalizer/draft-artem-n-20261007-009-texel`; её результаты не переносятся автоматически на 1.2.2. В этой поставке исходник 1.2.2 находится внутри ZIP.

Происхождение: принципы проверки углов и зеркальности адаптированы из ATRIUM AGR 2.0 (Timofei Zhilin); сам ATRIUM AGR в ZIP не включён.
