# UV Texel Equalizer

Автор разработки и передающий участник: **Nagornov Artem** (`nagornov-artem`); исходный `bl_info.author` оставлен `Codex`. Версия **1.1.0**, статус **validated только для синтетических тестов Blender 5.0.0**. Приёмка человеком на проекте коллеги отсутствует; `accepted` не присвоен.

Часть задачи стекла ВПМ: **DRAFT-artem-n-20261007-009**, [Trello XRE5EEOB](https://trello.com/c/XRE5EEOB). Связь подтверждена пользователем при первичном сборе 16.10.2026. Это отдельный инструмент в той же карточке, а не новая карточка и не реализация всего NTR-AI-001.

Аддон выравнивает плотность всех UV-островов активного меша и отдельно исправляет зеркальность/направление верха. Не делает unwrap, упаковку, согласование сетки разрезов или исправление геометрических нормалей. В отчёте есть исходные искажения, неоднозначности, пересечения и ограничения float32. Модификаторы не вычисляются; разрешение текстуры вводится пользователем.

Среда: Blender заявлен 4.3+/5.x, фактически повторено в **5.0.0** (hash `a37564c4df7a`). Зависимости: встроенные `bpy`, `bmesh`, Python `math/json/struct/collections`; pip-зависимостей и runtime-зависимости от ATRIUM AGR нет. Лицензионное происхождение адаптированных принципов требует отдельного уточнения: [provenance](docs/provenance.md).

Установка: `dist/uv_texel_equalizer_v1_1_0.zip` через Preferences → Add-ons → Install from Disk; либо открыть `src/uv_texel_equalizer.py` в Text Editor и Run Script. Интерфейс: UV Editor → N → Texel. Сначала выполнить аудит на копии объекта; затем исправление ориентации и/или выравнивание. Запуск/регистрация не меняют UV. Кнопки изменения применяют UV к активному мешу; отмена Ctrl+Z. `.blend` автоматически не сохраняется. [Полная исходная инструкция](docs/original-readme.md) сохранена byte-for-byte и содержит исторические утверждения, отличающиеся от текущего протокола проверки.

Проверка 16.10.2026: **15/15 плотность, 18/18 ориентация, ZIP smoke PASS**, только синтетические меши, `--background --factory-startup --python-exit-code 1`. [Кейс и запуск](cases/case-001-synthetic/case.md), [логи](reports/current/), [handoff](jobs/draft-artem-n-20261007-009-texel/handoff.md).

Исходный код и ZIP скопированы без изменения алгоритмов. Последний доступный пользовательский кейс завершился защитным отказом по точности; успешное производственное применение текущих bytes не установлено. Клиентские `.blend`, изображения и результаты отсутствуют в поставке.
