VPM Auto UV 0.2.0 — инструкция для Blender 5.0
============================================================

Это ранее разработанный аддон без изменений кода. Архив содержит
сам аддон и служебный модуль уже существующей кнопки сварки .009.
Дополнительные самостоятельные скрипты обработки UDIM, проёмов,
восьми рядов и отражённых UV сюда не добавлены.

1. Установка
------------------------------------------------------------
1) Скачайте VPM_Auto_UV_0_2.zip. Распаковывать его не нужно.
2) В Blender откройте Edit → Preferences → Add-ons.
3) В меню со стрелкой в правом верхнем углу выберите Install from Disk.
4) Выберите ZIP и установите его. Включите VPM Auto UV, если он
   не включился автоматически. Если старая копия уже установлена,
   сначала отключите и удалите её через Preferences → Add-ons.
5) Вернитесь в 3D Viewport. Нажмите N и откройте вкладку VPM.
   Панель называется VPM Auto UV.

2. Подготовка сцены
------------------------------------------------------------
Сохраните отдельную копию .blend до обработки. При успешных
операциях исходный объект заменяется результатом; скрытые копии
для отката не сохраняются. Модификаторы, видимые во вьюпорте,
фиксируются в результирующей геометрии, трансформации запекаются.
Объекты с Shape Keys предварительно переведите в статический меш.

Проверьте физический размер модели и Scene Properties → Units.
Если 1 Blender Unit соответствует 1 метру, используйте Unit Scale = 1.
Аддон учитывает Unit Scale; ошибочный масштаб сцены даст ошибочный
размер нарезки. Обрабатывается активный mesh, а не вся коллекция.
Работайте в Object Mode.

3. Основная последовательность
------------------------------------------------------------
1) Выделите нужный меш и откройте панель N → VPM.
2) Укажите:
   • «Тексель, px/м»: 1000;
   • «Текстура, px»: 2048;
   • «Начало сетки, м»: (0, 0, 0), если не нужна другая привязка.
   Получится шаг общей сетки 2.048 м: 2048 / 1000.
3) Нажмите «Подготовить UV».
   Создаётся мировая проекция UV в слое VPM_GRID.
4) Нажмите «Нарезать общую сетку XYZ».
   Весь меш режется общими плоскостями поверх существующих рёбер.
   Общие вершины сохраняются. Планарные квадраты специально
   на четыре части не делятся; исходные рёбра остаются.
5) Нажмите «Сложить квадраты в 1001».
   Активным становится UV-слой VPM_TILE_1001. Нарезанные участки
   переводятся в квадрат U=0…1, V=0…1 с перекрытием островов.
   Их масштаб сохраняется: фрагменты меньше целой ячейки
   не растягиваются до полного квадрата.
6) Откройте UV Editor и проверьте развёртку, затем сохраните
   результат отдельным .blend.

Параметры нарезки фиксируются при нажатии «Подготовить UV».
Не перемещайте объект и не меняйте масштаб сцены между подготовкой
и нарезкой. Если нужно изменить параметры, вернитесь к исходной
копии сцены и повторите последовательность с новыми настройками.

4. Текстура и швы
------------------------------------------------------------
Используйте бесшовную тайловую текстуру. Аддон не генерирует
изображение, не создаёт материал и не выбирает карту автоматически.
Если в материале есть узел UV Map с явным именем старого UV-слоя,
выберите в нём VPM_TILE_1001. Иначе материал может показывать
прежнюю развёртку, хотя новая уже создана.

Для соседних объектов задавайте одинаковые плотность, разрешение
и начало мировой сетки. Основная последовательность обрабатывает
каждый активный объект отдельно и не сваривает его с соседями.
На углах, наклонных поверхностях и асимметричных изображениях
проверяйте рисунок визуально; точное совпадение всех швов не обещается.

5. Уже существующая специальная кнопка .009
------------------------------------------------------------
Кнопка «Нарезать .009 и сварить с Main» — отдельный режим,
разработанный для конкретного состава сцены. В этом исходном
архиве нужны два объекта с точными именами:

Main
SM_NizhnieMnevniki_ZU_66_001_Main.009

Кнопка доступна в Object Mode, если оба объекта существуют
и операция ещё не помечена как выполненная. Она использует
сохранённые параметры сетки Main, согласует границы и объединяет
часть с Main; объект части после успеха удаляется. UV Main
сохраняется. Это не универсальная кнопка сварки любых объектов.
Для обычного меша пользуйтесь последовательностью из раздела 3.

6. Проверка результата и ограничения
------------------------------------------------------------
• Режется весь меш, но это не ретопология: прежние рёбра и треугольники
  могут остаться внутри ячеек. Неплоские полигоны могут триангулироваться.
• Плотность точна на поверхностях, параллельных главным плоскостям.
  На наклонных и криволинейных участках возможны сжатия UV.
• Базовая кнопка складывает UV только в UDIM 1001. Восемь рядов по Z,
  подбор других UDIM по цвету НПМ, проёмы и исправление отражений
  не входят в эту последовательность.
• Подготовка и нарезка заменяют активный объект; его имя может
  получить суффиксы _VPM и _CUT. Остальные объекты не обрабатываются.
• Отчёты доступны в Text Editor Blender в блоках *_report.json:
  шаг, плотность, количество граней, площадь и сжатие на наклонах.
• Есть защитные пределы: до 2000 режущих плоскостей и до 2 млн граней.
  Для слишком большого входа разделите задачу пространственно.
• Надёжный откат — открытие сохранённой копии до обработки.

Архив передан без изменения исходного кода. Проверка регистрации
и основной последовательности выполнена отдельно в Blender 5.0.0
на синтетическом кубе; открытый рабочий проект не использовался.
