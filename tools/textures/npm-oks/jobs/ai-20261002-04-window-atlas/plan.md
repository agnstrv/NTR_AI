# План

1. Исследовать коллекцию source и три цели. Прочитать протокол Ромы; проверить ветки и PR.
2. Проба на характерных секциях. Исходные данные и наблюдения не считать общими нормативами.
3. Модули: классификация исходника по согласованным ID; согласованная вертикальная нарезка; растеризация и группировка; упаковка; проверка.
4. Единый frame соседних копланарных частей, общие точки на исходных рёбрах. Сохранение smooth и модификаторов. Неплоские узкие грани не разрезать автоматически.
5. Упаковка без поворота в 1024×2048, проверка рамок и отступов. Сравнить необходимую детализацию с вместимостью.
6. Проверки геометрии и PNG независимыми агентами; отдельный статический review.
7. Финальная копия, отчёт, handoff. Обезличенные код и документы — commit+push; человеческая приёмка остаётся открытой.

Откат: исходный blend не перезаписывается. Генератор запускается с factory startup, без пользовательских аддонов. Клиентские модели, исходные геометрические дампы, текстуры и превью находятся вне Git.
