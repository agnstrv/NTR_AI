# Выдавливание нижней кромки НПМ

Автор ветки: Артём Нагорнов. Статус: prototype. Trello ID не подтверждён.

`extend-base.py` выдавливает заданные свободные рёбра вниз по мировой оси Z и переносит материал примыкающей грани. На каждую новую грань отводится свой прямоугольник в согласованной цветовой плашке атласа. Рёбра определяются в копии подготовленной модели, после завершения основной геометрии и UV.

```powershell
blender --factory-startup -b input.blend -t 4 --python-exit-code 1 --python extend-base.py -- --plan base.json --depth 2 --output extended.blend
```

`base.json` связывает имя объекта с индексами рёбер его меша в текущем файле. Индексы отсчитываются с нуля. Для каждого UV-слоя меша указывается прямоугольник `[u_min, v_min, u_max, v_max]` внутри подготовленной плашки. Верх новой полосы соответствует `v_max`. Для меша без UV укажи `"uv": {}`.

```json
{
  "ExampleFacade": [
    {"edge": 0, "uv": {"UVMap": [0.05, 0.10, 0.08, 0.20]}},
    {"edge": 1, "uv": {"UVMap": [0.08, 0.10, 0.12, 0.20]}}
  ]
}
```

План составляется вручную по индексам и цветам исходной кромки. Свободное ребро должно иметь ровно одну грань. Допустимы цепочки и замкнутые контуры без разветвлений, с общими нижними вершинами на стыках. Низ остаётся открытым. Режим единиц None считается как 1 м на единицу Blender, в остальных режимах используется масштаб единиц сцены. Требуются одноэкземплярные меши без shape keys и пользовательских нормалей. Применимость к нужным UV-плашкам и стеку модификаторов проверяется на копии сцены.

Если используются атрибуты граней с идентификатором зоны атласа, проверь и при необходимости переназначь их после выдавливания. Скрипт наследует значения примыкающей грани.

Проверено в Blender 5.0.0 на синтетическом контуре с поворотом, неравномерным масштабом и UV. Проверялись мировое смещение на 2 м, непрерывность, направление граней, исходные UV и новые полосы.

```powershell
blender --factory-startup -b -t 4 --python-exit-code 1 --python test-extend-base.py
```
