# Карты материалов по готовому атласу НПМ

Автор ветки: Артём Нагорнов. Статус: prototype. Trello ID не подтверждён.

`build-surface-maps.py` работает с готовым RGB-атласом. Для стекла Roughness равен 0, Metallic равен 255. Для остальных пикселей значения обратные. Если передать готовую двоичную карту прозрачности, скрипт проверит её и запишет карту с теми же значениями пикселей. Результаты сохраняются в RGB PNG в разрешении исходного атласа.

Требуются Python 3.10+ и Pillow. Скрипт запускается без Blender.

```powershell
python src/build-surface-maps.py --atlas color.png --plan glass.json --output surface-maps
python src/build-surface-maps.py --atlas color.png --plan glass.json --opacity source-opacity.png --output surface-maps-with-opacity
```

Координаты в `glass.json` целочисленные, от верхнего левого угла. Правая и нижняя границы исключаются. Укажи области окон и отдельные плашки стекла, включая используемые UV-поля вокруг них. Для каждой области перечисли фактические RGB-значения стекла. Метки вне этих областей игнорируются. Каждый цвет должен встретиться в заданном прямоугольнике.

```json
{
  "glass_regions": [
    {"box": [0, 0, 256, 180], "colors": [[240, 241, 244]]},
    {"box": [288, 0, 512, 240], "colors": [[235, 236, 240], [240, 241, 244]]}
  ]
}
```

Подходит для атласов с плоскими цветами. Совпадение точное, поэтому для JPEG, градиентов или сглаженных границ стекла обычно нужна отдельно подготовленная маска. Если стекло и другой материал имеют одинаковый цвет внутри окна, уточни область до самого стекла. Прозрачность берётся из указанного входа. При подключении используй карты как данные Non-Color.

`python tests/test-surface-maps.py` проверяет карты на искусственном RGB-атласе, включая одинаковый цвет на стекле и вне области, точную инверсию, совмещение с бинарной прозрачностью и отклонение полутонов в маске.
