# Фасадные профили НПМ

Сборка геометрии балконов и горизонтальных поясов по подготовленным планам. Для балконов используются два замкнутых перила и одностороннее заполнение. Для поясов поддерживаются кольцевые и локальные профили с несколькими ступенями по высоте.

## Входные данные

Подготовьте контуры, места установки и отметки по исходнику в мировых координатах рабочей сцены. Один юнит Blender равен одному метру. Контуры задаются в XY, высоты по Z. Контур каждого перила и сечения задаётся точками в порядке обхода без повтора первой точки. Промежуточные точки позволяют сохранить закругления в полигональном приближении. При необходимости заведите торцы балкона в стену в самом плане. На данном этапе материалы, атлас и UV настраиваются отдельно.

### Балконы

[Пример JSON](tests/example-balconies.json) содержит массив `balconies`. В каждой строке укажите контур перил `rail_xy`, открытую траекторию заполнения `infill_xy`, интервалы отметок двух перил `lower_z` и `upper_z`. Траектория заполнения должна проходить сквозь план перил. Расположите её точки в таком порядке, чтобы наружная сторона была справа по ходу обхода, если смотреть на план сверху. Параметр `overlap_m` задаёт вертикальный заход заполнения в каждое перило, по умолчанию 0,001 м. Три результирующих меша содержат целочисленный атрибут грани `balcony_index` с индексом строки плана от нуля.

В примере команда запускает Blender 5.0 в фоне. Укажите путь к рабочей сцене после `-b` и имя новой выдачи в `--output`. Для привязки к существующей коллекции активной сцены добавьте `--collection ИмяКоллекции`. Без параметра объекты добавляются в корневую коллекцию активной сцены.

```powershell
blender --factory-startup -b input.blend -t 4 --python-exit-code 1 --python src/build-facade.py -- balconies --plan tests/example-balconies.json --output with-balconies.blend --prefix balconies
```

### Пояса

[Пример JSON](tests/example-belts.json) содержит массив `belts`. Для каждого пояса задайте `mode` со значением `wrap` для кольца или `local` для локального участка. В `layers` задайте последовательные слои снизу вверх. В каждом слое укажите интервал `z`, замкнутый контур наружной поверхности исходного профиля `source_xy` и замкнутый контур тела башни `body_xy`. Верхняя отметка одного слоя совпадает с нижней отметкой следующего, а их сечения перекрываются по площади. Разделяйте участок на слои там, где меняется сечение тела башни или профиля. Для сквозных отверстий тела и наклонных стен корректность заданного сечения требуется проверять по исходнику.

`projection_m` расширяет наружный контур по умолчанию на 0,01 м. `embed_m` задаёт внутреннюю границу пояса со смещением от контура тела по умолчанию на 0,05 м. Для кольца алгоритм замыкает сечение по границе внутри тела. Сетка точности `grid_m` по умолчанию равна 0,0001 м, смещения округляются к ней. Смещения строятся с острыми углами и ограничением длины угла. Слои стыкуются по общей разбивке плана, поэтому у ступеней нет внутренних крышек.

Для расчёта сечений нужен Python с Shapely 2.1 или новее и GEOS 3.10 или новее. Запускайте расчёт отдельным Python. Импорт в Blender использует только модули Blender и стандартную библиотеку.

```powershell
python src/plan-belts.py --input tests/example-belts.json --output belts-mesh-plan.json
blender --factory-startup -b with-balconies.blend -t 4 --python-exit-code 1 --python src/build-facade.py -- belts --plan belts-mesh-plan.json --output with-facade.blend --prefix belts
```

Сверьте стыки и пересечения с существующей геометрией на рабочей копии. Программа проверяет топологическую замкнутость и направление граней перил и поясов. Положение заполнения относительно перил в плане задаёт оператор. Для отдельных поясов в местах примыкания к другим объектам может потребоваться скорректировать отметки в плане и повторить сборку.

## Воспроизводимая проверка

Запустите команды из каталога пакета. Используйте новые имена файлов при повторной проверке.

```powershell
blender --factory-startup -b -t 4 --python-exit-code 1 --python src/build-facade.py -- balconies --plan tests/example-balconies.json --output sample-balconies.blend --prefix sample-balcony
python src/plan-belts.py --input tests/example-belts.json --output sample-belts-plan.json
blender --factory-startup -b sample-balconies.blend -t 4 --python-exit-code 1 --python src/build-facade.py -- belts --plan sample-belts-plan.json --output sample-facade.blend --prefix sample-belt
blender --factory-startup -b sample-facade.blend -t 4 --python-exit-code 1 --python tests/verify-examples.py
```

Синтетическая проверка пройдена в Blender 5.0.0 и Shapely 2.2.0. Проверены замкнутость и объёмы перил, направление нормалей и вертикальный нахлёст заполнения, замкнутость, объёмы и фактические смещения кольцевого и локального поясов. Точность переноса на новый объект зависит от подготовленных контуров. Автор переноса `nagornov-artem`. Статус: prototype. Trello ID не подтверждён. Исходные схемы обобщены из производственного сценария среднего НПМ.
