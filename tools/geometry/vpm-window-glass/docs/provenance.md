# Происхождение и упаковка

Источник: разрешённая пользователем read-only папка исторической сессии `x20`, дата каталога 05.10.2026, подкаталоги `outputs` и `work`. Чат «Окна ВПМ», ID `01a10aeb-d5a6-7d01-9ab8-d0beb190755c`. Файлы прочитаны 16.10.2026; исходники не изменялись. Полные личные пути не публикуются.

[source-manifest.json](source-manifest.json) содержит исходные относительные имена, SHA-256 до/после и все замены байтов. Алгоритмы, численные параметры, порядок импортов и окончания строк не менялись. Замены ровно двух типов: исходное имя BIM-меша → `WindowFrameSource`; выражение с абсолютным корнем сессии → `Path(__file__).resolve().parents[1]`. В manifest точный приватный литерал представлен SHA-256, чтобы не публиковать клиентский идентификатор. Сравнение с разрешённым оригиналом однозначно восстанавливает каждую замену по этому хешу; новые значения и количество вхождений указаны открыто. Других изменений файлов исходного кода нет.

У `src/experimental/unify_manifold_v4.py` относительный корень указывает на `src/`, как и у `outputs`; остались исторические пути `outputs/Impost_Before.blend` и `work/result.json`. Клиентский файл не прилагается. Это исполняющийся при загрузке отвергнутый сценарий: он открывает/сохраняет .blend, меняет геометрию и очищает материал. Не импортировать и не использовать на рабочем проекте.

Не копировались исходный ZIP (содержит более ранний поднабор), .blend/.blend1, подробные JSON координат/профилей, снимки, модельные временные файлы и средства управления живой сценой. Вместо подробных клиентских отчётов записаны только агрегаты в кейсе. Связь с другими карточками/задачами не назначалась автоматически; пользователь отнёс плейны и Equalizer к ...009.
