Статус: **prototype**. Сохранены исходные алгоритмы, включая подготовительные и незавершённые части. Текущие синтетические проверки отдельных функций не подтверждают воспроизводимость всего процесса на другом здании. Приёмка человеком и production-проверка отсутствуют.

Это несколько последовательных исторических сценариев, а не аддон с одной кнопкой. [Сценарий и ограничения](docs/workflow.md), [происхождение и точные изменения байтов](docs/provenance.md), [план и передача](jobs/draft-artem-n-20261007-009-planes/handoff.md), [исторический кейс](cases/historical-window-case.md).

Среда исходной работы и текущих синтетических проверок: Windows, Blender **5.0.0**. Нужны `bpy`, `bmesh`, `mathutils`, NumPy из Blender и стандартная библиотека Python; версия NumPy отдельно не фиксировалась. Другие версии Blender не проверены. Самостоятельные preprocessing-скрипты также требуют NumPy. GUI bridge для живого Blender не включён: упаковка его не использует.

## Что сохранено

`src/outputs/`: семь исходных модулей — создание плейнов, наружное смещение/нормали, вырезы, cleanup, quad retopology, заполнение середины толщины и непрерывные листы. Имена файлов сохранены ради внутренних ссылок. `src/work/`: пять исторических скриптов подготовки профилей. `src/experimental/`: отвергнутый union импостов, **не запускать как стекло**.

Удобный начальный этап на **копии** согласованной сцены: сохранить все модули `src/outputs/` рядом, назначить исходному мешу алиас `WindowFrameSource`, открыть сохранённый `window_planes.py` в Blender Text Editor → Run Script. `main()` создаёт плейны и применяет наружное расширение 0,10 м через соседний `window_plane_adjust.py`. Требуется Unit Scale = 1. Запуск может менять геометрию и выделение сцены. Для программного вызова есть `main(source_name=..., adjust=False)`; не менять нейминг исходника ради этапов, у которых имя передаётся параметром.

Дальнейшие этапы нельзя запускать вслепую через Run Script: см. workflow. Infill и continuous требуют внешних геометрических JSON; эти данные намеренно отсутствуют в Git. Итоговые стеклянные материалы и UV/texel не завершены этой упаковкой; [UV Texel Equalizer](https://github.com/agnstrv/NTR_AI/tree/work/nagornov-artem/uv-texel-equalizer/draft-artem-n-20261007-009-texel/tools/uv/uv-texel-equalizer) — отдельная разработка той же карточки в независимой ветке, доступность её ветки нужно проверить перед использованием.

## Проверка

В отдельном процессе Blender с `--background --factory-startup --python-exit-code 1 --python <tool>/docs/synthetic-check.py` проверяются импорт семи модулей и пять контрактов: расширение прямоугольника на 2 см, clip, проекция профиля, repair T-junction, отказ без источника. Результат — [synthetic-check.json](cases/synthetic-check.json). Ни клиентские сцены, ни GUI не открываются. Повтор всего исторического кейса и checker остаются следующему участнику.
