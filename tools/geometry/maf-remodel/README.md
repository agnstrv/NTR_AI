# Перемоделирование и облегчение МАФов

Автор рабочего подхода: Рома. Подготовка: Codex совместно с Ромой, 12–13.11.2026. Тип: workflow для совместной работы, не универсальный автоматический ремешер. Статус: **prototype**; независимой приёмки на проекте коллеги нет.

- [Запустить из папки Ромы](../../../Рома/Перемоделирование%20МАФов.md).
- [Полный сценарий и обязательное вступление агента](workflow.md).
- [Передача публикации](jobs/publish-workflow/handoff.md).

Основная область: лавочки, урны, столики, стулья, ограждения и сходные элементы. Крупные сборки и повреждённые переплетения требуют разбиения на меши и поэтапной проверки. Приблизительное восстановление формы и авторское изменение композиции — разные решения; последнее согласуется с пользователем.

Наблюдавшаяся среда: Blender 5.2.2 LTS и Blender MCP. Версию, доступность инструментов и единицы сцены проверять при каждом новом проекте. Для чтения/редактирования документации модель не нужна. Альбомы, геометрия, текстуры и отчёты с координатами не входят в эту публикацию.
