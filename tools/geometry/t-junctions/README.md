# Поиск и локальная сшивка Т-стыков

Автор ветки: nagornov-artem. Статус: prototype. Trello ID не подтверждён. Проверено в Blender 5.0.0 на синтетических мешах. Один объект, Object Mode, исходная сетка до модификаторов. Работайте на копии, а выход и JSON храните вне репозитория, если в них есть клиентские данные.

## Поиск

```powershell
blender --factory-startup -b input.blend -t 4 --python-exit-code 1 --python src/t-junctions.py -- scan --object Shell --distance 0.0001 --report candidates.json
```

Скрипт ищет вершины рядом с внутренней частью каждого ребра в мировых единицах Blender. Число в примере иллюстрирует синтаксис. Допуск выбирайте по масштабу объекта и точности источника. `--endpoint-clearance` задаёт минимальную дистанцию до концов и между новыми узлами. По умолчанию она равна `--distance`. Отчёт содержит пару индексов концов ребра, число инцидентных граней, индекс каждой вершины, её параметр вдоль ребра, расстояние и число граней на двух коротких отрезках, если они уже существуют. Без `--report` JSON записывается в stdout. Сцена в этом режиме только читается.

Совпадение координат даёт кандидата. Подтвердите, что это одна проектная кромка. Близкие грани разных оболочек, внутренние рёбра, разрывы и складки требуют отдельного решения. Для цепочки с несколькими узлами проверьте каждый последовательный короткий отрезок.

## Сшивка подтверждённого открытого шва

Подготовьте JSON по индексам вершин того же входного файла. Пары `edge` обозначают концы длинных рёбер, `vertices` перечисляет уже существующие промежуточные вершины. Скрипт сортирует их вдоль ребра. Проверьте, что версия сцены после поиска совпадает со входом сшивки.

```json
{"splits": [{"edge": [0, 1], "vertices": [3]}]}
```

```powershell
blender --factory-startup -b input.blend -t 4 --python-exit-code 1 --python src/t-junctions.py -- split --object Shell --distance 0.0001 --plan stitch.json --output stitched.blend
```

Длинное ребро должно принадлежать ровно одной грани, а каждый короткий отрезок встречной цепочки — ровно одной другой грани и иметь противоположное направление. Скрипт вставляет существующие вершины в контур длинной грани. Координаты вершин сохраняются, нарезка граней в треугольники остаётся отдельной операцией. Старые UV сохраняются, UV новых углов интерполируются на исходном ребре каждой грани. Материалы, сглаживание, активные UV-слои и флаги seam/sharp сохраняются. Blender может сбросить выделение в редакторе UV и изменить индексы граней и рёбер. Перед сохранением проверяются инцидентность и связность веера вокруг вершин шва. Указывайте свободный выходной путь с расширением `.blend`.

Сшивка рассчитана на отдельный локальный mesh datablock без shape keys, модификаторов, групп вершин, пользовательских нормалей, или дополнительных атрибутов кроме UV и штатных флагов. Она отклоняет планы без полной встречной цепочки, с тройными рёбрами или разрывом веера. Почти компланарная складка также отклоняется, когда угол между геометрическими нормалями соседних граней отличается от 180° не более чем на 2°. Произвольные взаимопересечения скрипт не проверяет. Проверяйте такие места вручную с учётом нормалей и данных модели.

## Синтетическая проверка

```powershell
blender --factory-startup -b -t 4 --python-exit-code 1 --python tests/test-synthetic.py
```

Проверяются два размера цепочки, отличающийся соседний UV, материал и сглаживание, сохранение XYZ, противоположная инцидентность, отклонение близкой посторонней вершины, неверного winding, компланарного перекрытия и неподдерживаемых атрибутов. Шов под прямым углом проходит. Командный тест также сохраняет и переоткрывает исправленный синтетический файл.
