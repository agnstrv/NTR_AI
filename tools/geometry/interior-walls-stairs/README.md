# Создание внутренних стен и лестниц

Автор процесса: Рома (roman-kasyan). Тип: workflow. Статус: prototype.
Редакция: 18.11.2026.

[Открыть сценарий](workflow.md) · [Передача](jobs/draft-20261118-workflow/handoff.md) · [AI-review](jobs/draft-20261118-workflow/review.md)

Назначение: визуальное моделирование внутренних стен, стеклянных перегородок, дверей и затем лестниц по альбому с привязкой к готовой модели здания. Мебель, сантехника, отделка, IFC и подсчёты не входят в согласованный объём.

Входы: существующая модель, актуальный альбом, согласованный охват и папка рабочих копий.
Выходы: сохранённая модель с согласованными участками, показ результата и запись допущений.
Запуск: передать агенту workflow.md и указать проект и источники. Агент задаёт только оставшиеся вопросы по этапам.

Среда исходного опыта: Windows, Blender 5.2.2 LTS по журналу диалога. При этой публикации Blender и checker повторно не запускались. Независимая проверка на проекте коллеги и приёмка человеком ещё нужны; статус accepted не присвоен.

Trello: соответствующая карточка не установлена после поиска по стенам и лестницам. Чужие задачи по фасадному стеклу и UCX не использованы как ID этой работы. Временный job draft-20261118-workflow — идентификатор документационной упаковки, не выдуманный ID Trello. Следующий шаг: связать с подтверждённой карточкой.

Отдельный сценарий интерьеров не меняет выбор лёгкой/средней версии [НПМ ОКС](../../textures/npm-oks/README.md).
