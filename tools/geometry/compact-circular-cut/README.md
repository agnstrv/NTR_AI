# COMPACT-CUT-001 — Compact Circular Cut 1.1.1

Аддон Blender для локального вычитания цилиндра с короткими сходящимися рёбрами вокруг отверстия. Исходные рёбра и перегибы поверхности сохраняются; соседние короткие рёбра объединяются к более редкой внешней сетке. Контур и размер задаёт цилиндр пользователя.

**[Скачать установочный ZIP](dist/compact_circular_cut_v1.1.1.zip?raw=true)** · [Исходники аддона](src/compact_circular_cut) · [Standalone-скрипт](standalone/circular_cut_compact.py)

Ручной эталон: принцип пользователя — от каждой вершины круглого выреза выходит короткое ребро, соседние окончания сходятся к меньшему числу внешних вершин. На кривой поверхности нельзя заменять исходные рёбра длинными диагоналями, даже если их концы проецируются на поверхность.

## Установка и запуск

Проверенная среда: Windows, Blender **5.0.0**, аддон **1.1.1**. Другие версии Blender не проверялись. Используются встроенные `bpy`, `bmesh`, `mathutils`; внешние библиотеки не нужны.

1. Скачать ZIP, не распаковывая его. Открыть **Preferences → Add-ons → Install from Disk**, выбрать ZIP и включить **Compact Circular Cut**.
2. При обновлении отключить прежнюю версию, установить ZIP, сохранить работу и перезапустить Blender. В панели должна появиться строка **«Версия 1.1.1»**. Backend также принудительно перезагружается при обновлении, чтобы исключить выполнение старой логики из кеша.
3. В **Object Mode** создать прямой замкнутый цилиндр минимум с 8 сторонами и расположить его на участке выреза.
4. Выделить цилиндр, затем с Shift выделить целевой меш **последним**, сделав его активным.
5. В **3D Viewport → N → NPM** нажать **«Сделать вырез»**. Также доступна команда **F3 → Compact Circular Cut** и пункт меню **Object**.

Вход: два меша, активный — поверхность, второй — цилиндр. Выход: изменённый активный меш; резак остаётся и по умолчанию скрывается. Ширина перехода по умолчанию — `0.16` радиуса резака, настраивается в панели. Поворот и масштаб резака учитываются без обязательного Apply Transform. Для сквозного выреза цилиндр пересекает обе стороны замкнутого меша; для глухого один торец находится внутри него.

Запускать на копии модели. Отмена — **Ctrl+Z**. Регистрация аддона сама по себе не изменяет сцену. Новая версия не исправляет уже сделанное отверстие автоматически: отменить старую операцию либо взять исходный меш и повторить вырез.

## Сетка и ограничения

В местах пересечения исходных рёбер с профилем резака могут добавляться коллинеарные вершины. Размер и профиль сохраняются, но итоговый контур может содержать больше вершин, чем цилиндр: они нужны для сохранения формы поверхности. Барицентрическая проекция и ограниченная триангуляция сохраняют исходные линии; где возможно, возвращаются плоские многоугольники без лишнего дробления.

Поддерживаются открытая поверхность, сквозное отверстие, глухое углубление, нечётное число сторон, поворот и неравномерный масштаб цилиндра. Не поддерживаются конусность, фаски и меняющийся профиль резака, вырезы через внешний край или через уже имеющееся отверстие, более двух отдельных слоёв, shape keys. При очень узком переходе относительно малого числа сторон операция может быть отклонена: увеличить ширину. Перед ошибкой валидации исходный меш не изменяется.

Вырез строится на базовой сетке целевого меша; результат после его модификаторов нужно проверить. UV поверхности интерполируются, новые внутренние стенки получают полосу 0–1, требующую размещения в рабочем атласе. После операции вручную проверить контур, исходные рёбра, силуэт, сглаживание, ориентацию граней и плотность сетки. Проверка на одном примере не гарантирует результат на произвольной архитектуре.

## Воспроизводимые проверки и сборка

Из корня этой папки:

```powershell
blender --background --factory-startup --python-exit-code 1 --python tests/test_geometry.py
python tools/build_addon.py
```

Тест создаёт только синтетические объекты; примеры и JSON-отчёт сохраняются в папку `compact_cut_test_output` рядом с папкой эксперимента. Проверяются профиль резака и сохранность его исходных вершин, короткие рёбра, связность и ориентация граней, замкнутость сквозных и глухих вырезов, поворот, масштаб, нечётные сегменты, большие координаты, общие mesh-data и отказ без изменения меша при неподдерживаемом вырезе.

[Сводка выполненных проверок](reports/validation.json): установка ZIP, панель, два цикла включения/отключения, перезагрузка намеренно устаревшего backend, геометрические сценарии. Отдельная локальная проверка примера пользователя: сохранены все 54 проверяемых участка исходных рёбер; отклонение от исходной прямой меньше 0.000001 единицы Blender. Сам пример в репозиторий не загружается.

Версия 1.0.0 меняла кривизну длинными диагоналями. В 1.1.0 сохранены исходные рёбра; в 1.1.1 исправлена загрузка устаревшего backend при обновлении. Успешную ручную проверку подтвердил пользователь 13 октября 2026 года. Следующий шаг — независимая проверка на другом примере и назначение владельца перед статусом accepted. Путь в tools при этом не меняется.
