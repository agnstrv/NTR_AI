# Памятка: как работать с Codex в репозитории NTR

Одна страница. Git и правила агент знает сам — тебе нужно запомнить только это.

## Один раз на ПК
1. Открыть Codex в папке репозитория NTR_AI (Артём поможет на созвоне).
2. Создать в корне файл `.ntr-user` с одной строкой — своим id из `team.md` (например `roman`).
3. Включить вечернюю сводку (Артём настроит): каждый вечер Codex сам собирает короткий отчёт о сессиях дня. Переписка не копируется — только время, режим, задача, результат.

## Каждая задача — три шага

**1. Начать.** Напиши как обычно: «привет, пришла задача…» или «хочу поработать над коллизиями».
Агент спросит:
- кто ты;
- что делаем: **обсуждение** / **контракт для агента** / **скрипт-тулза** / **применить готовое**;
- какой это этап пайплайна —
и покажет, что по теме уже сделали коллеги. Если готовое есть — сначала попробуй его.

**2. Работать.** Агент сам заводит ветку, задаёт вопросы пакетом и сначала делает короткий пилот. Твоя задача — отвечать конкретно и проверять результат в Max/Blender.
Всегда говори агенту, **сколько это заняло бы вручную** — из этого считается экономия.

**3. Сдать.** Скажи «**сдаю**» (или «на сегодня всё»). Агент сохранит результат по шаблону, отправит в свою ветку, откроет PR и даст текст для чата команды. В `main` вливает Артём.

## Правила, которые нельзя нарушать
- Клиентские файлы (модели, альбомы, текстуры) в GitHub не кладём. Работаем на копиях.
- Ничего не пушим в `main` и не делаем merge — только через «сдаю».
- Если взял чужой инструмент и попробовал на проекте — обязательно «сдаю» в режиме **применить готовое**: это и есть галочка «проверено коллегой».

## Где смотреть
- Что есть и в каком статусе: `STATUS.md` (или `status/dashboard.html`).
- Карта пайплайна и фокус недели: `roadmap/README.md`.
- Команда: `team.md`.
