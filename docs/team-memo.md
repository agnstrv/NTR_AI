# Памятка: Codex + репозиторий NTR_AI

Одна страница. Git и правила агент знает сам — тебе нужно помнить четыре команды.

## Один раз на ПК
1. Склонировать репозиторий `NTR_AI` в одну папку и открывать Codex в ней (в папках проектов копии не нужны).
2. Создать в корне файл `.ntr-user` с одной строкой — своим id из `team.md` (например `roman`).
3. Проверить, что Codex подключён к твоему личному GitHub.

## Четыре команды

| Пишешь | Когда | Что делает агент |
|---|---|---|
| `ntr` | новый чат, новая задача | спрашивает, чем занимаемся, где папка проекта, Blender или Max, сколько это занимает вручную; показывает готовые сценарии коллег; составляет паспорт задачи и план; после каждого шага ждёт твоё «принято» |
| `ntr-handover` | контекст заполнен на 40–50% | сохраняет состояние задачи на GitHub; после этого открой новый чат |
| `ntr-takeover` | новый чат после handover | находит последнее состояние и продолжает с того же шага |
| `ntr-retro` (или «сдаю») | задача закончена или не получилась | спрашивает время с нейронкой, записывает сценарий с версией, выгружает ветку и открывает PR |

В приложении Codex команды есть в списке по `/`, в терминале — `$ntr`. Можно и просто словом.

## Что от тебя нужно
- **Время.** На старте скажи, сколько задача занимает вручную, в конце — сколько ушло с нейронкой. Без этих двух чисел экономия на дашборде остаётся нулевой.
- **Приёмка.** Каждый шаг проверь в Blender или Max и ответь «принято» или что поправить.
- **Сдавай и неудачи.** «Не получилось, потому что…» — тоже результат: коллега не пойдёт тем же путём.

## Папка проекта
В папке проекта агент создаёт `AI/`:
- `input` — копии исходников для агента;
- `output` — черновые результаты;
- `finish` — то, что ты принял.

Исходники проекта агент не трогает. На GitHub уходят только текст и скрипты — модели, альбомы, текстуры и пути к папкам остаются на ПК.

## Контекст и модель
- Проверить заполнение: `/status`. После 40% ответы становятся хуже — делай `ntr-handover` и новый чат.
- Один чат — одна задача.

## Хороший запрос агенту
- что получить, с числами: размер атласа, тексель, платформа;
- чего быть не должно: треугольников, n-gon, оверлапов UV;
- пройтись по всем этапам, а не «сделай красиво».

Сценарий в `scenarios/` — это такой запрос, отлаженный и записанный, чтобы коллега запустил его в чистом чате.

## Пять слов про GitHub
- **Репозиторий** — общая папка команды в интернете.
- **Ветка** — твоя личная копия, где ты ничего не сломаешь другим. Твои ветки начинаются с `work/<твой id>/`.
- **Push** — отправить свою ветку на GitHub. Это делает агент по `ntr-handover` и `ntr-retro`.
- **PR** — заявка «посмотрите и примите мою работу в общую версию».
- **main** — общая проверенная версия. В неё вливает только Артём Сафро. Случайно попасть туда из своей ветки нельзя.
