# Подключение к репозиторию NTR — пошагово

Время: ~15 минут на ПК. Делаем на созвоне вместе.

## Что нужно заранее
- Codex установлен и вошёл в бизнес-аккаунт компании.
- Git установлен (`git --version` в PowerShell показывает версию).
- **Токен GitHub** (и Trello) от Насти — подключаемся по токену, без логина и пароля (решение 10.11). Токен никому не пересылать и в репозиторий не класть.

### Подключить токен GitHub (один раз)
```
git config --global credential.helper manager
```
При первом `git clone`/`git push` в окне входа выбрать вход по токену и вставить выданный токен. Git Credential Manager запомнит его.

## Шаг 1. Получить репозиторий
В PowerShell:
```
cd C:\Users\<ваше_имя>
git clone https://github.com/agnstrv/NTR_AI.git
```
Если папка уже есть: `cd NTR_AI` и `git pull`.

## Шаг 2. Кто работает на этом ПК
В корне `NTR_AI` создать файл `.ntr-user` с одной строкой — своим id:

| Кто | id |
|---|---|
| Артём Сафро | `artem-safro` |
| Артём Нагорнов | `artem-nagornov` |
| Роман Касьян | `roman` |
| Иван Проселков | `ivan` |
| Вячеслав | `slava` |

```
Set-Content -Path .\.ntr-user -Value roman -Encoding ascii
```
Файл в GitHub не уходит.

## Шаг 3. Открыть репозиторий в Codex
Codex → открыть папку `NTR_AI`. Агент сам прочитает правила (`AGENTS.md`) и скиллы.

## Шаг 4. Проверка
Напишите агенту: **«Привет, хочу проверить подключение»**.
Агент должен:
1. спросить, вы ли это (по `.ntr-user`);
2. спросить режим (обсуждение / контракт / скрипт / применить готовое);
3. вывести строку `NTR-SESSION user=... mode=...`.

Если агент сразу начал что-то делать без этих вопросов — скажите Артёму.

## Шаг 5. Вечерняя сводка (один раз)
PowerShell **от имени пользователя** (подставьте свой путь):
```
schtasks /create /tn "NTR daily journal" /sc daily /st 19:00 /tr "powershell -ExecutionPolicy Bypass -File C:\Users\<ваше_имя>\NTR_AI\scripts\ntr-daily.ps1 -Push"
```
Что делает: в 19:00 собирает короткую сводку ваших сессий Codex **в папке NTR_AI** (время, режим, задача, результат — без текста переписки) и отправляет её в ветку `journal`. Личные чаты вне репозитория не читаются.

Проверить вручную: `powershell -ExecutionPolicy Bypass -File .\scripts\ntr-daily.ps1` → появится `journal\<дата>\<id>.md`.

## Что почитать (5 минут)
- `docs/team-memo.md` — памятка на одну страницу.
- `STATUS.md` — что уже есть в реестре и в каком статусе.
- `roadmap/README.md` — карта пайплайна.

## Если что-то не так
| Проблема | Что делать |
|---|---|
| `git` не найден | установить Git for Windows, перезапустить PowerShell |
| Codex не видит GitHub / нет прав на push | написать Артёму — проверим плагин и доступ аккаунта |
| Агент не спрашивает «кто ты» | убедиться, что открыта именно папка `NTR_AI`, начать новую сессию |
| Сводка не создаётся | запустить `ntr-daily.ps1` вручную и прислать вывод Артёму |
