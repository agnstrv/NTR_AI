# ИИ в производстве NTR — как работаем дальше

Для: Сергей · От: Артём Сафро · 09.11.2026 · 1–2 страницы

## 1. Цель
Сократить время типового проекта на **30–35%** за счёт ИИ-инструментов, и видеть прогресс каждую неделю в часах и процентах.

| Типовой проект | Сейчас | Цель (−35%) |
|---|---|---|
| НПМ упрощённый | 40 ч (5 дн) | 26 ч |
| НПМ | 60 ч (7,5 дн) | 39 ч |
| ВПМ | 80 ч (10 дн) | 52 ч |

Часы и доли этапов — оценка 07.11, уточняются замерами на реальных проектах.

## 2. Что мешало (диагноз)
- **Нет общей картины.** У каждого свой пайплайн и свои эксперименты, результаты не складываются в одно целое («каша»).
- **Наработки невидимы.** 7 инструментов застряли в ветках, ни один не проверен коллегой; репозиторий не обновлялся с 13.10.
- **Работа с ИИ «в свободное время»** — без закреплённого времени и без замеров эффекта.
- **Trello дробный** (57 мелких карточек, у 30 нет исполнителя) и не связан с кодом.
- **Инфраструктура держится на одном человеке**: доступы к Trello, Zoom, GitHub.

## 3. Как работаем теперь
1. **Одна карта пайплайна.** 3 продукта × Ground/ОКС × этапы с часами. Все задачи и инструменты привязаны к этапу — поэтому видно, где и сколько сэкономили.
2. **Один репозиторий, общие правила для агента.** Codex у каждого начинает сессию одинаково: кто работает → что делаем (обсуждение / контракт для ИИ / скрипт / применить готовое) → что по теме уже есть у коллег → работа → «сдаю». Git за человека делает агент.
3. **Чужое — сначала попробовать.** Перед тем как делать своё, агент показывает, что уже сделали коллеги. Каждое применение чужого инструмента на реальном проекте фиксируется как «проверено коллегой».
4. **Замеры вместо ощущений.** Инструмент засчитывается в экономию только после замера «вручную → с инструментом» на реальном проекте.
5. **Отчётность автоматическая.** Вечером каждый ПК сам собирает сводку работы с агентом (только рабочие сессии в репозитории). Еженедельно собирается дашборд.

## 4. Что вы видите на дашборде
- Сверху: насколько уже сокращён каждый типовой проект и сколько осталось до цели −35%.
- Зрелость инструментов: сколько приняты в работу / проверены коллегой / замерены.
- Кто что внёс, топ-10 участков работы, работа с Codex по дням, состояние Trello.

Сейчас реальные цифры нулевые — замеров ещё не было. Демо-версия на синтетических данных показывает, как это будет выглядеть.

## 5. Ритм (согласовано 10.11)
- **Понедельник** — планирование: загрузка по проектам, сколько у каждого времени на ИИ и над какими станциями работаем.
- **Среда** — статус: динамика, затыки, советы друг другу.
- **Пятница** — итоги недели с вами по дашборду.

## 6. Первые две недели (09.11–22.11)
1. Онбординг: у каждого Codex работает по новым правилам, вечерняя сводка включена.
2. Команда согласует карту пайплайна и цифры часов; у каждой ячейки появляется владелец.
3. Все наработки из веток переносим в общий репозиторий — их становится видно.
4. Фокус: **флора и МАФы** в Ground НПМ (~40% времени граунда, наработки уже есть). Каждый пробует минимум один чужой инструмент на своём проекте.
5. Первые замеры «до/после» → первые реальные проценты на дашборде.

## 7. Моя роль
Владелец программы ИИ: стандарты и правила для агентов, приёмка инструментов в общий репозиторий, метрики и дашборд, еженедельный отчёт вам, обучение команды.

## 8. Что нужно от компании
1. **Сделать репозиторий приватным** (в отчётах будут названия проектов).
2. **Время на ИИ — отдельной строкой в оценке проектов.**
3. **Доступ к Trello и Zoom-записям не через одного человека.**
4. Команде открыто сообщить, что рабочие сессии с ИИ автоматически сводятся в отчёт (только работа в репозитории, без личных чатов).
