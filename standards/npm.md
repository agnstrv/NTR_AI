# НПМ — черновик для сверки

Из интервью: альбом и BIM-модель используются для архитектуры; DWG — для размещения по московским координатам. Описаны атласы 2048×2048 для архитектуры; ground, элементы и флора имеют разные схемы атласов. Параметры должны быть сверены с действующим техническим заданием и проверяющим плагином.

Статус: не утверждено. Источник: рассказ команды 29.09.2026.
