# Технические требования

Разделы `npm.md`, `vpm.md`, `ppt.md`, `ifc.md` заполняются только по утверждённым требованиям и проверенным выводам команды. Для каждого правила указываются источник, версия, область применения и проверка. Пока соответствующий документ не добавлен, не считать услышанные числовые параметры нормативом.

Найденные оригиналы и вопросы о редакции перечислены в [sources.md](sources.md).
