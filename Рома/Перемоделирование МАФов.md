# Перемоделирование МАФов

Автор рабочего подхода: Рома. Сценарий для совместной работы с Codex, статус prototype. Дата упаковки: 13.11.2026.

## Запуск

Скопируй в новый чат Codex:

> Запусти сценарий «Перемоделирование МАФов» из папки «Рома» репозитория NTR_AI. Прочитай полные правила tools/geometry/maf-remodel/workflow.md, кратко расскажи, что умеешь и какие есть ограничения, затем начни с осмотра указанного мной МАФа. Крупные и сложные объекты сначала разбирай на отдельные меши и проверяй по частям. Исходник сохраняй.

Можно передать Codex непосредственно [полный сценарий](../tools/geometry/maf-remodel/workflow.md). Для загрузки одного самостоятельного документа используй именно workflow.md: он содержит вступление и все правила. Сохранение файла на диске без передачи в контекст само по себе не запускает сценарий.

## Инструкция агенту при запуске этой точки входа

Прочитай связанный workflow.md полностью и выполни раздел «Запуск сценария в Codex». Если доступна только эта страница, получи полный документ из подключённого репозитория; при отсутствии доступа попроси предоставить его. Не заявляй, что полные правила прочитаны, пока они недоступны.

Сценарий охватывает осмотр, простые формы, сохранение оригинала, стыки, скругления, материалы, повторяющиеся объекты и подсчёт треугольников. Крупные и сложные МАФы пока нельзя обещать точно перестроить целиком: сообщи о сложности, предложи отдельные меши, начни с одного образца и затем проверяй сборку. Подключение к Blender проверяется отдельно; наличие этого файла не даёт управления сценой.

Полные правила имеют один источник: [workflow.md](../tools/geometry/maf-remodel/workflow.md). Информация о статусе: [README инструмента](../tools/geometry/maf-remodel/README.md).
