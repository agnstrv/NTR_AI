# Как внести вклад

1. Начните с [памятки](process/team-quickstart.md) и [нужного промпта](prompts/README.md).
2. Соблюдайте [структуру](process/repository-structure.md), [цикл агента](process/agent-harness.md) и [правила команды](process/team-workflow.md).
3. Одна задача — своя ветка; публикуйте commit + push. Перед слиянием требуется PR.
4. Сохраните проверенный commit, отчёт, ограничения и решение другого человека. Приёмка упаковки исследования отличается от готовности инструмента.
5. Клиентские данные остаются вне GitHub; старые пути и чужая работа сохраняются.

Правила требуют соблюдения участниками. Наличие этого файла не включает серверную защиту main.
