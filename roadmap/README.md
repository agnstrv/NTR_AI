# Roadmap: карта пайплайна

Мы не стандартизируем, **как** человек делает работу (Max или Blender, свои приёмы).
Мы договариваемся о **результате каждого этапа** — что на входе, что на выходе, как проверить.
К этапам привязываются инструменты, доли времени и экономия.

## Матрица

| Продукт | Ground | ОКС |
|---|---|---|
| НПМ упрощённый | `ground-npm` (общий) | `oks-npm-lite` |
| НПМ | `ground-npm` (общий) | `oks-npm` |
| ВПМ | `ground-vpm` | `oks-vpm` |

Каждая ячейка — список этапов с долей времени (`share`, % времени ячейки). Источник правды — `pipeline.json`.

## Две линии работы

- **Линия «контракты»** — то, что делает только нейросеть по контракту (анализ исходников, коллизии…). Результат: `contract.md`, который любой может запустить.
- **Линия «тулза NTR»** — скрипты и функции для Max/Blender. Цель — плагин NTR с вкладками по этапам.

В `pipeline.json` у этапа поле `line` — какая линия для него основная.

## Как считается экономия

`экономия этапа = (время до − время после) / время до` — только по **замеренным** значениям из реестра.
`экономия ячейки = Σ (доля этапа × экономия этапа)`; `экономия проекта ≈ экономия ячейки × доля ячейки в проекте`.
Оценки показываются отдельно и в итог не входят.
