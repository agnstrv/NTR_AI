# Скрипты 3ds Max

Для каждого инструмента: задача, версия 3ds Max, установка, вход, запуск, выход, ограничения, проверка результата, пример на обезличенных данных.

Новые инструменты размещаются по операции в tools/. [Каталог](../../tools/README.md) · [Правила структуры](../../process/repository-structure.md). Существующие пути сохраняются.
