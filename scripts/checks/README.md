# Проверки и исправления

Автоматическая проверка должна указывать источник требования и версию проверяющего инструмента. Исправление исходного файла запускается на копии и проверяется человеком.

Новые инструменты размещаются по операции в tools/. [Каталог](../../tools/README.md) · [Правила структуры](../../process/repository-structure.md). Существующие пути сохраняются.
