# Промпт 1 — собрать наработки
Скопируйте блок в локального агента. Заполните автора и папки. Запускайте после появления правил в main; до этого явно укажите ветку PR вместо main.

~~~text
Собери мои рабочие и незавершённые наработки для команды NTR.
Репозиторий: https://github.com/agnstrv/NTR_AI
Автор / slug: [имя / латиница]
Разрешённые рабочие папки: [полные локальные пути]
Карточки Trello, если известны: [ссылки]
Дополнительные доступные экспорты чатов: [пути или нет]

Сначала проверь доступ и текущий Git. Не превращай исходную рабочую папку в новый репозиторий поверх существующего. Для сборки используй отдельную копию NTR_AI или worktree.
Получи актуальный main и прочитай AGENTS.md, process/repository-structure.md, process/team-workflow.md, process/agent-harness.md и tools/README.md.
Составь опись только указанных папок и доступных чатов. Отсутствие доступа к другим чатам явно отметь. Исходники не удаляй и не перемещай.
Сопоставь каждую разработку с существующими папками, ID Trello, ветками и PR. Избегай повторной выгрузки. Новую карточку создавай только для действительно новой понятной задачи; неоднозначное соответствие уточни.
Собери код, сценарии, архитектурные решения, зависимости, инструкции, полезные неудачные попытки, кейсы и handoff. Отметь research/prototype/validated по доказательствам; не присваивай accepted сам.
Клиентские модели, текстуры, альбомы и тяжёлые результаты оставь вне GitHub; сохрани ссылки/версии, неизвестное отметь.
Каждую независимую задачу упакуй в отдельную ветку work/<author>/<tool>/<job-id> по правилам репозитория. Для существующей разработки используй её канонический путь.
Проверь изменения и проведи AI-review доступными средствами. Не переписывай алгоритмы ради упаковки и не выдумывай результаты тестов.
Сделай commit + push веток без merge в main. Обнови связанные карточки Trello ссылками на результат и реальным состоянием. Если доступа нет, подготовь текст обновления.
Дай таблицу: разработка, ID, путь, статус, ветка/commit, что проверено, что отсутствует, следующий шаг. Отдельно перечисли материалы, которые намеренно не опубликованы.
~~~
